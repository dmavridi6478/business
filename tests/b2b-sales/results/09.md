## Scoring rule

Stated before any score. Maximum 9.

- ICP fit: 4 points if industry, size and region all meet the ICP, otherwise 0.
- Signal relevance: 3 if the signal type is named in your signal-to-problem map, 2 if I mapped it by judgement, 0 if there is no mapping.
- Recency: 2 if the signal is 30 days old or less, 1 if 31 to 90 days, 0 if none. Recency counts only when relevance is above 0.
- Tie-break: the more recent signal ranks first.
