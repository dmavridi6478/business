## Exit scripts

Both drafts: draft, needs approval. Neither promises anything, gives a reason that is not in the inputs, or blames the prospect. Placeholders in braces. No alternative resource or referral exists in the inputs, so none is offered; add one if you have it.

Draft A, native SAP connector required (hard #1):

> Subject: Our SAP integration
>
> Hello {first_name},
>
> Thank you for being clear about the SAP connector. Tallyleaf currently supports CSV and SFTP file import and a read-only REST API. We do not have a native SAP connector, so we would not be the right fit if that is a firm requirement, and I would rather say so now than waste your time.
>
> If file import would be acceptable after all, reply and we can look at it again.
>
> Eleni Markou, Tallyleaf Ltd, 12 Example Street, Athens, Greece

Draft B, under 200 employees (hard #2):

>
> If the company grows or the process becomes harder to manage, you are welcome to contact me.
>
> Eleni Markou, Tallyleaf Ltd, 12 Example Street, Athens, Greece
