## First-value milestone

**Definition:** the first matching run on Redwater's own carrier invoices and shipment records, using the carrier rate cards loaded for Redwater, producing a matched set and an exception queue that the Controller's team reviews.

- **Planned for:** end of week 4, day 28 after kick-off [calc: 4 weeks x 7 days].
- **Done when:** (1) the run is logged by the system on real Redwater data, and (2) the Controller confirms in writing that she has seen the results.
- **Why this is the first value:** it is the earliest point where Redwater sees its own mismatches in an exception queue, which is the link to both success measures.
- **Check before promising anything about duplicates:** the confirmed capabilities on file are matching, the exception queue with reason codes, rate checks, accrual export and SSO. Duplicate-invoice detection is not named. Confirm with the product team how a duplicate shows up (for example as an exception reason code) before telling Redwater it will be caught.
