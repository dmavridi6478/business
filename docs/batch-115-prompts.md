# Batch 111 prompts (files numbered 115)

Plain-text prompts from this batch. Paste them into any assistant. Nothing here publishes, messages or installs anything.

## 1. Sell an unused item (five-step sequence, approval gates kept)

```
I want to sell [item]. Work in four steps and stop after each one for my OK.
1. Identify the item from my photos and compare recent comparable SOLD listings (not asking prices). Link every source and say how uncertain the price range is.
2. Write a clear title and description using only the condition and details I have confirmed. Ask me about anything you cannot see.
3. Prepare the photos and draft for [marketplace]. I will approve the price and publish. Do not post anything.
4. When buyers write, draft replies and negotiation options. I approve every commitment, payment and collection detail. Never share my address, phone number or payment details.
```

Before step 1, photograph the item, its model number, the condition and any defects, and remove private information. Command: `/sell-listing [item]`.

## 2. LinkedIn positioning line (T, U, D)

```
Help me write one LinkedIn positioning line using this formula: I help [target audience] get [value] by [differentiator].
Target audience: [who would reply if I messaged them tomorrow]
Value: [what they can do after working with me, as an outcome]
Differentiator: pick ONE of a method, a view, a proof point or a focus, and ask me for evidence of it.
Give two versions, tell me if either sounds like a CV, then tell me what to put in my headline, About, banner and posts. Use only numbers I can back.
```

Command: `/positioning-triangle [audience] | [outcome] | [differentiator]`.

## 3. Pick a go-to-market model

```
My situation: [product, stage, what feels stuck].
From the nine models (Bullseye, Positioning to Messaging, Growth Loops, PMF Cycle, Minimum Viable Segment, Van Westendorp price meter, Beachhead, ECP vs ICP, Validation Methods), pick one or two that fit, say which question each answers, give the order to use them (who, proof, message and price, growth) and the first concrete action for each. If you suggest Van Westendorp, state which convention you use for the marked points.
```

Command: `/gtm-model-pick [situation]`.

## 4. Pick a free tool for a job

```
Job: [what I need to do] on [Windows / macOS / Linux].
From WinDirStat, BCUninstaller, Shotcut, KeePassXC, DB Browser for SQLite, ImageMagick, Oh My Zsh, rich, mpv, SearXNG, pick one or two. For each give the licence, the platform, the install route as its README states it and the one risk. Tell me what to back up first. Do not install or run anything.
```

Command: `/oss-tool-pick [job]`.
