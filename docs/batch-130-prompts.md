# Batch 130 prompts (plain text, copy and paste)

The 18 rebuilt commands are the prompts. Run them as slash commands, or paste these one-line starters. All are original, written from the printed one-line jobs.

1. /delete-ai-words [draft] - cut clichés and AI phrasing, keep my voice, list every change.
2. /my-viral-post [topic, 2-3 past posts] - three drafts with different hooks in my style.
3. /infographic-builder [text or data] - 1080x1350 HTML infographic, every figure sourced.
4. /deep-research-synthesizer [notes and question] - sourced summary with gaps and confidence.
5. /deck-builder [outline] - Gamma deck if connected, otherwise a slide-by-slide spec.
6. /linkedin-hook [topic] - ten opening lines, ten hook types.
7. /fable-prompter [rough draft, target model] - a clean prompt with placeholders and tests.
8. /negotiation [situation] - walk-away, target, trades, opening line.
9. /excel-style [file, style rules] - format only, never change values, save a new file.
10. /hormozi-viral-1 [belief, evidence] - contrarian post in a generic structure (not Hormozi's own).
11. /meeting-notes [transcript] - summary, decisions, actions with owners, open questions.
12. /client-brief [company] - one-page, sourced, read-only brief.
13. /linkedin-post-report [export] - what the numbers mean, three experiments.
14. /viral-recipe [post and results] - repeatable parts versus luck.
15. /meeting-visualizer [notes] - interactive HTML dashboard published as an Artifact.
16. /tc-social-carousel [topic, brand] - six-layout Instagram carousel drafts.
17. /reddit-researcher [question] - quotes with links and dates from Reddit, X and YouTube.
18. /fact-checker [text] - every claim marked supported, partly, unsupported or unverifiable.
