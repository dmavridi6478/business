# 9 Claude commands (@the.wealth.lab)
Tagline: "Better prompts. Better output."

| # | Name | Prompt | Repo command |
|---|---|---|---|
| 1 | Start with questions | Before you answer, ask me the most important questions you need to give me the best possible result. | `/clarify-first` |
| 2 | Red team this | Red-team this idea. Identify the weaknesses, risks, blind spots, and assumptions. Then suggest how to strengthen it. | `/redteam` |
| 3 | Compare options | Compare these options in a table. Include the pros, cons, risks, and your recommendation based on my goal. | `/compare-options` |
| 4 | Give me examples | Give me 3 strong, realistic examples so I can clearly see what a good result looks like. | `/examples` |
| 5 | Expert mode | Approach this like a top [FIELD] expert with 20 years of experience. Give me practical, strategic advice and explain your reasoning. | `/expert-mode` |
| 6 | Simplify it | Explain this in simple, plain language, as if you were teaching a 12-year-old. Use one clear example. | `/simplify-explain` |
| 7 | Rewrite for tone | Rewrite this to sound sharper, clearer, and more persuasive while keeping my original meaning and voice. | `/rewrite-sharper` |
| 8 | Keep going | Keep going until the task is fully complete. Review your work, fix any gaps, and don't stop after the first pass. | `/keep-going` |
| 9 | Find the bottleneck | Analyze this project or process and identify the biggest bottleneck. Explain why it's limiting progress and give me the simplest high-impact solution. | `/find-bottleneck` |

Use one command per turn; chain 1 then 5 then 8 for important work.
