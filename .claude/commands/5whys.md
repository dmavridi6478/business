# /5whys

Drill down 5× with "Why?" to find the true root cause of a recurring problem.

## Usage
```
/5whys [problem statement]
```

## Example
```
/5whys Our deployment pipeline keeps failing on Friday afternoons
/5whys Customers are not activating past the trial's first week
```

Invokes the `exec-problem-solving` skill → Root Cause Analysis / 5 Whys framework.
