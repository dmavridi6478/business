# /premortem

Assume failure. Work backward to prevent it before a launch or initiative.

## Usage
```
/premortem [initiative, launch, or decision]
```

## Example
```
/premortem our Q4 product launch targeting enterprise customers
/premortem expanding into the German market in 6 months
```

Invokes the `exec-problem-solving` skill → Pre-Mortem Analysis framework.
