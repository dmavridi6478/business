# 10 Claude Prompts for Vibe Coding

Save-worthy prompts for building faster with AI. Source: @datawarlord_official

---

## Prompt 1 — Build a Full App

```
Build a complete [app name] using [technology]. Create a modern, responsive UI, include all essential features, and make every feature fully functional. Use clean, reusable, well-structured code. Avoid placeholders unless absolutely necessary.
```

---

## Prompt 2 — Clone a Website

```
Recreate this website: [website URL]. Match the design, layout, colors, spacing, and overall user experience as closely as possible. Make it fully responsive for mobile and desktop, and ensure all visible buttons and interactions work properly.
```

---

## Prompt 3 — Fix Bugs in My Project

```
Analyze my entire project and identify bugs, errors, broken functionality, and incorrect logic. Explain the root cause of each important issue, then fix it without breaking existing features. Also clean up any unnecessary or duplicate code you find.
```

---

## Prompt 4 — Improve My Existing Project

```
Review my existing project and improve the code quality, UI/UX, performance, and project structure. Keep the original functionality intact, but refactor poorly written code, improve reusable components, and make the final result cleaner and more professional.
```

---

## Prompt 5 — Add a New Feature

```
Add [feature name] to my existing project. First understand how the current codebase works, then integrate the feature properly with the existing design and architecture. Make it fully functional, handle possible errors, and avoid breaking any existing functionality.
```

---

## Prompt 6 — Build a Landing Page

```
Create a high-converting landing page for [product or service]. Use strong headlines, clear sections, persuasive copy, and prominent calls to action. Make the design modern, responsive, fast, and easy to scan.
```

---

## Prompt 7 — Build an Admin Dashboard

```
Create an admin dashboard for [business or app]. Include overview cards, charts, tables, filters, and key actions. Make it clean, intuitive, responsive, and easy to navigate.
```

---

## Prompt 8 — Refactor My Codebase

```
Refactor my codebase for readability, maintainability, and scalability. Remove duplication, simplify complex logic, improve file structure, and preserve all current functionality.
```

---

## Prompt 9 — Add Tests & Documentation

```
Add meaningful tests and clear documentation to my project. Cover the critical user flows, explain setup and usage, and make the codebase easier for other developers to maintain and extend.
```

---

## Prompt 10 — Deploy My App

```
Help me deploy [app name] to production. Set up the hosting environment, configure environment variables, optimise the build, and make sure the app is live, stable, and accessible at a public URL.
```

---

## Quick-swap cheatsheet

| Placeholder | Replace with |
|-------------|-------------|
| `[app name]` | Your app's name (e.g. "task manager", "CRM") |
| `[technology]` | Stack (e.g. "React + Supabase", "Next.js + Prisma") |
| `[website URL]` | The URL you want to clone |
| `[feature name]` | Specific feature (e.g. "dark mode", "CSV export") |
| `[product or service]` | What you're selling |
| `[business or app]` | Your dashboard subject |
