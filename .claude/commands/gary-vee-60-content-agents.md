# 60 Claude Agents on Gary Vee's $200M Organic Marketing

Source: "60 Claude Agents on Gary Vee's $200M Organic Marketing" infographic —
built on how Gary Vee grew a $200M business through organic content,
community and brand. A named-role checklist across 8 stages, ~7-8 agents
each. These are role names, not full prompts — pick a role, then write the
prompt for what that role should actually do. Cross-reference
`claude-revenue-system-58-agents` (same pattern, revenue-cycle territory
instead of content/community) and `content-pipeline` /
`content-strategy` skills for the deeper workflow these roles slot into.

## Plain-text prompt to turn a role into a working agent

```
Act as the [ROLE NAME] from the $200M Organic Marketing system. Given this
input — [PASTE: raw footage notes / analytics export / platform data /
whatever this role needs] — do this role's job: [DESCRIBE WHAT YOU EXPECT,
e.g. "pull 5 story angles from these raw clips" for Story Identification
Agent, or "flag which platforms are under-indexed for this content type"
for Platform Arbitrage Agent]. Output as [FORMAT — ranked list, table,
one-pager, calendar].
```
