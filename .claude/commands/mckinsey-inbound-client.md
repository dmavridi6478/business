You are a high-ticket inbound activation specialist. Run all 8 agents in sequence for "$ARGUMENTS":

**Agent 01 — Buyer Signal Detection**
List 10 specific buyer signals to monitor on LinkedIn and email. Include: post engagement signals, profile view patterns, comment behaviour, DM triggers, and content consumption signals. For each signal, specify what it means and what action to take.

**Agent 02 — Warm Prospect Identification**
Define the "hot prospect" criteria (score 8+/10). Build a daily 15-minute monitoring checklist with specific platforms to check, signals to score, and a simple CRM note format.

**Agent 03 — Comment Engagement**
Write 20 comment templates across 4 types: (1) adds a new insight, (2) asks a power question, (3) challenges respectfully, (4) shares a relevant experience. Each comment must invite dialogue and never feel like a pitch.

**Agent 04 — Inbound Lead Routing**
Design a 4-stage qualification matrix: Signal Detected → Qualified → Conversation Started → Discovery Booked. Define the trigger, action, and script snippet for each transition.

**Agent 05 — Profile Viewer Outreach**
Write a 3-message DM sequence for people who viewed the profile:
- Message 1 (Day 1): Warm, curious, no ask
- Message 2 (Day 4): Provide a specific piece of value
- Message 3 (Day 10): Soft invite to connect or explore

**Agent 06 — Post Engager Response**
Write response templates for 4 engager types on posts:
- Enthusiastic supporter: deepen the connection
- Sceptical commenter: engage with curiosity, not defence
- Asking for more: provide value and open a thread
- Competitor or peer: professional, confident, brief

**Agent 07 — Warm Signal Scoring**
Create a 1–5 scoring rubric for inbound signals. Define what each score means and which score triggers which action (observe / engage / outreach / book call).

**Agent 08 — Inbound Pipeline Management**
Design a lightweight CRM workflow for inbound leads. Include: pipeline stages, daily actions (5 min), weekly pipeline review checklist (10 min), and how to decide when to archive a prospect.

Deliver each agent clearly labelled. Scripts must be ready to use without editing.
