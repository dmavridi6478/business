# /profitability-ratios

Calculate and interpret the 12 key profitability ratios for any business.

## Usage
```
/profitability-ratios [company name or paste P&L + balance sheet data]
/profitability-ratios explain [ratio name]
```

## Examples
```
/profitability-ratios Apple Q4 2024
/profitability-ratios explain ROCE
/profitability-ratios [paste financial data]
```

Invokes the `profitability-ratios` skill.
