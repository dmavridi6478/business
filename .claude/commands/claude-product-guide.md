## THREE CLAUDE PRODUCTS

---

### CLAUDE AI
**What it is:** A conversational AI assistant designed for everyday thinking, writing & analysis.

**Where to use:**
- Draft emails, essays, reports and long-form content
- Brainstorm and explore ideas conversationally
- Research, summarize and explain complex topics

**Pros:** Zero setup needed · Versatile & general
**Cons:** No system access · Manual follow-up

**Workflow:** Prompt → ChatUI → Claude Models → Output (limited memory, limited tools)

---

### CLAUDE CODE
**What it is:** A command-line tool that runs Claude as an autonomous coding agent directly in your terminal.

**Where to use:**
- Build or debug entire features across multiple files
- Refactor legacy codebases at scale autonomously
- Write and run tests, fixing failures automatically

**Pros:** Fully autonomous · Deep codebase context
**Cons:** Needs careful review · Usage costs apply

**Workflow:** Prompt → CLI UI ↔ Claude Models → File-system Memory + Multi-File editing → Write/Build (feedback loop)

---

### CLAUDE COWORK
**What it is:** A desktop application for non-developers that automates file management and repetitive tasks.

**Where to use:**
- Organize, rename and sort files across folders in bulk
- Extract data from PDFs and fill spreadsheets automatically
- Automate copy-paste workflows between applications

**Pros:** No coding needed · Cross-app workflows
**Cons:** Beta / early stage · Less control/config

**Workflow:** Prompt → Chat UI ↔ Claude Models → Organize files / Edit-update file / Multi-cross app workflows → Output

## QUICK DECISION GUIDE

| If you need to... | Use |
|---|---|
| Write, brainstorm, or research | Claude AI |
| Build, debug, or refactor code | Claude Code |
| Automate file/app workflows | Claude Cowork |
| Autonomous multi-file engineering | Claude Code |
| Zero-setup quick help | Claude AI |
