argument-hint: [the text to check, and any sources you already have]

Input: $ARGUMENTS

Use `verify-common-claim`, `sourcecheck` and `research-and-self-factcheck`.

1. List every checkable claim (numbers, dates, quotes, causal statements) numbered.
2. For each, find the original source (not a repost), give link and date, and mark: supported, partly supported, unsupported, unverifiable. Quote the line that decides it.
3. Note stale figures and context that changes the meaning. Never mark supported from memory alone.
4. Return a corrected version only if I ask.
