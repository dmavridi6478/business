---
description: Build or review a project plan using the 8-step order with a completeness check
argument-hint: <project name and what it must achieve>
---

Use the `project-plan-8-steps` skill. Input: "$ARGUMENTS"

1. Collect the objective, deadline, sponsor and constraints in one batch of questions.
2. Fill the eight steps in order; unknown values are written 'TBC - owner - date'.
3. Run the eight-line completeness check and show failing lines first.
4. Offer to export the plan as DOCX or XLSX using the docx/xlsx skills.
