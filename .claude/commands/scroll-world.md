# /scroll-world

Invoke the `scroll-world` skill to build an immersive, scrollable 3D brand website.

## Usage

```
/scroll-world [brand name] [optional: tagline, colors, vibe]
```

## Examples

```
/scroll-world Vertex Studio — "We build brands that move"
/scroll-world NomadCo dark muted palette, adventure/travel agency
/scroll-world LuxeLiving luxury real estate, gold and obsidian
```

## What you get

A single self-contained HTML file with:
- Scroll-driven 3D parallax animations (Three.js + GSAP ScrollTrigger)
- Hero → Story → Featured Work → Contact CTA sections
- Cinematic typography, rich dark palette, floating depth effects
- Mobile-responsive, 60fps smooth
