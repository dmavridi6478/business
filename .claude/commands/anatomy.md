# /anatomy

Generate an AI image prompt for a **cross-section cutaway** product visualization.

## Usage
```
/anatomy [product name] [optional: style notes]
```

## Example
```
/anatomy Sony WH-1000XM5 headphones
/anatomy Apple Vision Pro internal components, ultra-detailed
```

Outputs a ready-to-paste prompt for Midjourney, DALL-E 3, Firefly, or Flux.
