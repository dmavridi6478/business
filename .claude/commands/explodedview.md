# /explodedview

Generate an AI image prompt for an **exploded-view parts diagram** product visualization.

## Usage
```
/explodedview [product name] [optional: detail level, background]
```

## Example
```
/explodedview DJI Mavic drone
/explodedview mechanical keyboard, numbered components, blueprint style
```

Outputs a ready-to-paste prompt for Midjourney, DALL-E 3, Firefly, or Flux.
