# /six-hats

Apply Six Thinking Hats to unlock balanced team decisions and prevent groupthink.

## Usage
```
/six-hats [decision or topic]
```

## Example
```
/six-hats whether to raise prices 20% for existing customers
/six-hats acquiring a competitor vs building the feature ourselves
```

Invokes the `exec-problem-solving` skill → Six Thinking Hats framework.
