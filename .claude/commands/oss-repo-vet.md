description: Vet an open-source repo before cloning or self-hosting it (licence, activity, install method, data it touches)
argument-hint: <owner/repo>
---

Use skill `oss-repo-cards-batch-115`. For "$ARGUMENTS" check from the README, LICENSE and recent commits: what it does, licence and what that means if I host it for others, last commit and open-issue health, the install method (flag any piped installer), what data or credentials it touches, and what it needs to run (SMTP, API keys, Docker). Say which of my existing skills already cover it. Verdict: clone, trial in a container, or skip. Clone nothing.
