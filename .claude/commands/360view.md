# /360view

Generate an AI image prompt for a **360-degree product turntable showcase**.

## Usage
```
/360view [product name] [optional: colorway, finish, background]
```

## Example
```
/360view Sony α7 IV camera
/360view Nike Air Jordan 1, black/red, white seamless background
```

Outputs a ready-to-paste prompt for Midjourney, DALL-E 3, Firefly, or Flux.
