## Plain-text prompt to turn a role into a working agent

```
Act as the [ROLE NAME] from the Claude Revenue System. Given this input —
[PASTE: account data / call transcript / pipeline export / whatever this
role needs] — do this role's job: [DESCRIBE WHAT YOU EXPECT, e.g. "flag
buying signals and rate each high/medium/low" for Buying Signal Detector,
or "score fit/need/urgency/authority" for Lead Qualifier]. Output as
[FORMAT — table, ranked list, one-pager].
```
