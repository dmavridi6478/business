# 6 Stages of LinkedIn Personal Branding

Source: workflows.io infographic (Fivos Aresti).

A full-funnel view — profile through to booked meeting — with the specific
tool named at each stage. Use alongside this repo's existing
`linkedin-profile-audit`, `linkedin-growth-audit-checklist`,
`linkedin-week-content-plan`, and `linkedin-authority-builder` commands,
which go deeper on stages 1 and 3-4; this framework's distinct value is
stages 2, 5, and 6 (network expansion, lead capture, and retargeting), which
those don't cover.

## 1. Profile Optimization
- Banner
- Description
- Featured
- Experience
- CTAs

## 2. Network Expansion
- Follow 20-30 creators with 10k-100k followers, comment daily
- Build an ICP connect list (via Clay / HeyReach), send 20+ connection requests/day

## 3. Content Strategy
- **Positioning** → drives **Content Pillars**: Tech Stack, GTM Playbooks, Content Playbooks, Entrepreneurship
- **Content Mix**: TOF (top of funnel), MOF (middle), BOF (bottom)

## 4. Content Creation
- Design system + content pipeline (Idea → In Progress → QA → Live)
- LinkedIn routine: engage 30 min before posting → post manually → engage 30 min after

## 5. Lead Capture
Five parallel capture points, each with a named tool:
| Channel | Tool |
|---|---|
| Engagement | Jungleraw (or similar comment-automation tool) |
| Lead magnet opt-ins | Tally |
| Connections | LinkedIn |
| Website visits | Apollo.io |
| Direct bookings | Cal.com |

## 6. Retargeting
All five capture points feed one **Enrichment** step (Clay), which fans out to:
- Email (Instantly)
- LinkedIn DM (HeyReach)
- Cold call (Nooks)
- LinkedIn ads (Fibbler)
- → **Meetings Booked** (Ergo / booking tool)

---

## The stack, by category

- **Prospecting/enrichment:** Clay, Apollo.io
- **Outreach automation:** HeyReach, Instantly, Nooks
- **Content/scheduling:** a design system + kanban pipeline (any board tool)
- **Lead capture:** Tally (forms), Cal.com (booking)
- **Ad retargeting:** Fibbler (or equivalent LinkedIn ad retargeting tool)

None of these are self-hosted/open-source — they're commercial SaaS tools
named as-is in the source. If you want a self-hosted alternative to any one
of them, check this repo's `self-hosted-docker-stack` skill first before
signing up for a new paid tool.
