# AI Infographic Creation Guide

Create professional infographics in seconds using AI tools: $ARGUMENTS

---

**THE 5-STEP AI INFOGRAPHIC WORKFLOW:**

1. **Define goal** — Decide what the infographic should achieve (awareness, education, action)
2. **Write prompt** — Be specific about topic, audience, tone, structure, and data
3. **Choose tool** — Pick an AI tool (e.g., Napkin AI, Canva AI, Google Nano Banana Pro)
4. **Refine output** — Improve layout, colors, text, and accuracy with edits
5. **Export** — Download in PNG/PDF/SVG and adapt for different platforms

---

**THE ANATOMY OF A PERFECT INFOGRAPHIC PROMPT:**

`Topic + Structure + Tone + Style + Audience + Format`

**Weak prompt:** "Make an infographic about productivity."

**Strong prompt:**
> Create a 5-section vertical infographic on deep work for busy professionals, with stats, minimal design, navy & gold, icons, for LinkedIn (25–45).

---

**PRO TIPS FOR PROMPTING AI INFOGRAPHIC TOOLS:**

- Set number of sections
- Ensure text readability
- Define colors
- Specify visual style (e.g., funnel, timeline)
- Iterate and refine

---

**RECOMMENDED AI TOOLS BY USE CASE:**

| Use case | Tools |
|---|---|
| Data-heavy infographics | Canva AI, Piktochart AI, Google Nano Banana Pro |
| Research/explainer visuals | Napkin AI, Infogram, Whimsical, Google Nano Banana Pro |
| Fully generative images | Google Nano Banana Pro |
| Social media infographics | Adobe Express AI, OPT-Image 1.5, Google Nano Banana Pro |

---

**INFOGRAPHIC TYPES:**

- **Statistical** — Research, reports, surveys
- **Process** — Step-by-step guides, tutorials
- **Timeline** — History, milestones, evolution
- **Comparison** — Tools, pricing, before/after
- **Educational** — Explain complex topics
- **Geographic** — Regional data, trends

---

**MISTAKES TO AVOID:**

- Too much data — Focus on 3–5 key points; avoid clutter
- No audience defined — Specify who it's for
- Wrong size — Use correct aspect ratios for each platform
- No accuracy check — Verify stats, dates, and facts
- Poor text readability — Ensure text is clear on mobile
