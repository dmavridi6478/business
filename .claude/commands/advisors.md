---
description: Run the five-advisor LLM council on a decision and give a verdict
argument-hint: [decision, stated neutrally]
---

Run the `llm-council-5-advisors` skill on: "$ARGUMENTS". Restate the decision neutrally first (remove any leading framing). Then give each advisor (Contrarian, First Principles Thinker, Expansionist, Outsider, Executor) 3-5 lines, then the verdict: where they agree, the sharpest disagreement, the recommendation, and the cheapest test to run first.

If "$ARGUMENTS" is empty, ask for the question or input first.
