# /atm-audit

Run a brand visibility audit using the ATM Framework (Audience Growth → Trust & Engagement → Monetization).

## Usage
```
/atm-audit [brand or organization name] [optional: paste available metrics]
/atm-audit Acme Corp — social media growing, weak backlinks, high NPS but low pipeline conversion
/atm-audience [brand] — Audience Growth pillar only
/atm-trust [brand] — Trust & Engagement pillar only
/atm-monetization [brand] — Monetization pillar only
```

Invokes the `atm-framework` skill.
