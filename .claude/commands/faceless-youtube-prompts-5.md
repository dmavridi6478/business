# Faceless YouTube Automation Prompts (5)

Source: @martiendejong_dev. The source carousel's cover slide claims "7 blacklisted ChatGPT prompts" — only 5 numbered prompts (1-5) were present in the uploaded images; the other 2 are not reproduced here since they weren't actually shown, per this repo's standing rule against filling in content that wasn't captured.

These 5 prompts overlap conceptually with this repo's existing `yt-niche`, `yt-script`, and `yt-calendar` commands (which are more structured/interactive versions of the same jobs) — use those for a guided build; use the prompts below as quick one-shot copy-paste versions from a different source.

## 1. Niche Finder

```
List 15 Faceless YouTube niches with low competition, high growth potential,
and high RPM metrics that must be >$7.
```

## 2. Viral Content Blueprint

```
For [chosen niche], give me 20 viral video ideas that are relevant in 2025
that I can recreate without showing my face.
```

## 3. Script Writer

```
Model [insert viral competitor video] script and generate a new script that
is optimized for retention. Model YouTube best practices to ensure the best
results.
```

## 4. Content Generation (stock footage + AI video gaps)

```
Provide a list of 10 websites offering free stock footage relevant to my
video topic. Then, craft the ideal prompt for generating any missing video
clips using OpenAI Sora 2.
```

## 5. Content Calendar

```
Build me a 30-day content calendar for my YouTube channel, optimized for
engagement, fast monetization, and growth.
```
