# /productad

Generate an AI image prompt for a **commercial product advertisement hero shot**.

## Usage
```
/productad [product name] [optional: surface, mood, color grade]
```

## Example
```
/productad Nescafé Gold jar
/productad Dior perfume bottle, marble surface, purple smoke, luxury
```

Outputs a ready-to-paste prompt for Midjourney, DALL-E 3, Firefly, or Flux.
