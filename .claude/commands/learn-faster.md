Use the skill `learn-faster-7-prompts`. The first word of "$ARGUMENTS" is the prompt number (1 to 7); the rest is the topic and any extra detail (level, goal, time per day, timeframe).

1. Read `.claude/skills/learn-faster-7-prompts/SKILL.md` and take the prompt with that number exactly as written.
2. Fill the [BRACKETS] from the arguments. If a bracket has no value (for example [LEVEL] or [TIME]), ask for just those values in one short message before starting.
3. Then DO what the prompt says, starting with its first step. Teach in the chat; one question at a time where the prompt says so; never show an answer before the learner attempts it.
4. At the end of each session, give a short list of weak topics to paste into the next session.

If the number is missing or not 1 to 7, show the table from the skill and ask which one.
