# /yt-script

Write a complete YouTube video script using the proven faceless channel formula.

## Usage
```
/yt-script [video title] [niche] [target length] [tone]
```

## Example
```
/yt-script "7 AI Tools That Will Replace Your Team in 2026" AI productivity 10 minutes informative
/yt-script "How I Made $5,000 in 30 Days With No Experience" finance 12 minutes storytelling
```

Invokes the `yt-faceless-channel` skill → Video Script Formula prompt.
