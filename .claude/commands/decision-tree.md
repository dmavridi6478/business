# /decision-tree

Map choices, probabilities, and expected values for a high-stakes decision with uncertainty.

## Usage
```
/decision-tree [high-stakes decision with multiple options]
```

## Example
```
/decision-tree raise a Series A now vs bootstrap 12 more months
/decision-tree hire a VP Sales vs promote internally vs use an outsourced sales firm
```

Invokes the `exec-problem-solving` skill → Decision Tree Analysis framework.
