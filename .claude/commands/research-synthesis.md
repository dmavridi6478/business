Run the `docs/procedures/research-synthesis.md` six-stage synthesis against
the sources in "$ARGUMENTS" (paste the papers/abstracts/sources directly,
reference files already in this conversation, or reference a URL/dataset
the user has provided). If no sources are present yet, ask for them before
proceeding rather than synthesizing nothing.

Run all six stages against the same source set, in this exact order, each
building on what the previous stage found. Don't skip stages or merge them
— each is deliberately narrow so it catches something the others miss.
Label each stage's output clearly before moving to the next.

1. **Knowledge Map** — orient in the field first: core concepts and how
   they connect, sub-fields and their focus, key researchers/schools of
   thought, how understanding evolved over time, and where the field is
   heading based on recent work.

2. **Literature Review** — synthesize across all sources by theme, not
   paper-by-paper: consensus, where sources disagree and why, most common
   methodology, and the most-cited finding per theme.

3. **Gap Finder** — find what's missing, not what's covered: unanswered
   recurring questions, understudied populations/contexts, methodological
   limitations, untested assumptions, and the most promising unexplored
   direction.

4. **Contradiction Detector** — surface direct disagreements, don't smooth
   them over: what's disputed, which sources are on each side, why the
   contradiction likely exists (different populations/methods/definitions),
   and which position has stronger evidence.

5. **Methodology Auditor** — evaluate evidence quality: most common
   research designs and why, methodological weaknesses (name the weakness,
   name the source), what a stronger design would look like, and whether
   each source's conclusions are actually justified by its methods.

6. **Executive Brief** — synthesize stages 1-5 into one page: the field in
   2 sentences, the 3 most important findings for a decision-maker, the 2
   biggest remaining uncertainties, practical implications right now, and
   what we'll likely know in 5 years that we don't today. Plain language,
   no jargon — written for a smart non-expert who has to act on this. This
   is the only stage that should stand alone as something shareable
   without the other five attached.
