# /first-principles

Strip all assumptions. Rebuild the solution from foundational truths.

## Usage
```
/first-principles [problem or assumption to challenge]
```

## Example
```
/first-principles why we need a sales team to grow B2B revenue
/first-principles our pricing model — why charge per seat?
```

Invokes the `exec-problem-solving` skill → First Principles Thinking framework.
