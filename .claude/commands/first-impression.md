Use the skill `first-impression-5-prompts`. Input: "$ARGUMENTS".

1. Start with "The prompt to save" from the skill: ask 5 questions one at a time about the meeting, the user's real background and the goal.
2. Then produce, in this order: a natural introduction (10, 30 and 60 second versions), 3 conversation starters, 2 things worth sharing, 3 mistakes to avoid.
3. Offer prompt 04 (practice with 5 realistic questions, feedback after each answer) as the next step.
4. Use only facts the user gave. Never invent achievements; flag any line that sounds rehearsed.
