Input: "$ARGUMENTS". If any of the three parts is missing, ask for it one at a time.

Use `.claude/skills/linkedin-positioning-triangle/SKILL.md`.

1. T: sharpen the audience into a group that would reply to a message tomorrow. Reject "business owners".
2. U: rewrite the value as an outcome the audience recognises, not a service description.
3. D: offer the four kinds (method, view, proof point, focus) and ask the user to pick one. Four differentiators is the same as none.
4. Write the line: "I help [target audience] get [value] by [differentiator]." Give two variants and read each aloud as a test; it must not sound like a CV.
5. Place it: headline, About (open with the line, then prove it), banner (one-line offer), posts (audience and view in hooks and the closing line). Use the same wording in all four.
6. Run the checks: self-identification in five seconds, a measurable outcome, one piece of proof for D, and only numbers the user can back.

Do not publish or edit a profile. End with `Not verified:` for any claim the user has not evidenced.
