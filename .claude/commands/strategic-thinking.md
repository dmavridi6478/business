## THE 8 ELEMENTS

### 1. Vision
Strategic thinkers see what others miss — not just where things are, but where they're going.

- Set a clear, long-term direction that guides every decision
- Think in 3–5 year horizons, not just quarters
- Ask: "If we succeed, what does the world look like?"

**Prompt:**
```
Help me clarify my strategic vision for [business / product / career / team].
Current state: [where we are now]
Desired state: [where we want to be in 3–5 years]
1. Write a sharp, inspiring vision statement (1–2 sentences).
2. Identify the biggest gap between current and desired state.
3. What would I need to believe for this vision to be achievable?
```

---

### 2. Analysis
Good strategy is built on a clear-eyed understanding of reality — not assumptions or wishful thinking.

- Gather data before forming opinions
- Distinguish between signal and noise
- Use structured frameworks (SWOT, Porter's Five Forces, PESTLE) to map the landscape

**Prompt:**
```
I need to analyze [market / competitor / situation / opportunity]: [DESCRIBE IT].
Help me:
1. Identify the 3 most important facts I need to understand this situation.
2. What data or research would sharpen this analysis?
3. Run a [SWOT / Porter's Five Forces / PESTLE] on it.
4. What am I most likely wrong about?
```

---

### 3. Problem Solving
Strategic thinkers solve the *right* problem — not just the visible symptom.

- Define the problem precisely before jumping to solutions
- Use root-cause analysis (5 Whys, fishbone, issue trees)
- Generate multiple options before committing to one

**Prompt:**
```
The problem I'm trying to solve is: [DESCRIBE PROBLEM].
Help me:
1. Is this the real problem, or a symptom of something deeper? Use the 5 Whys.
2. Reframe the problem statement to make it more solvable.
3. Generate 4 different approaches — including one unconventional one.
4. Which approach best fits my constraints: [TIME / BUDGET / TEAM SIZE / RISK TOLERANCE]?
```

---

### 4. Focus
Strategy is as much about what you *don't* do as what you do. Focus creates leverage.

- Ruthlessly prioritize the few things that drive the most value
- Say no to good ideas that distract from great ones
- Protect attention as a resource

**Prompt:**
```
I'm currently trying to pursue [LIST OF GOALS / INITIATIVES].
My constraints are [time / team / budget].
Help me apply strategic focus:
1. Which of these creates the most leverage toward [my main goal]?
2. What should I stop, pause, or delegate?
3. What's the single most important thing I could do in the next 90 days?
```

---

### 5. Synthesis
Strategic thinkers connect dots across domains — turning information into insight.

- Find patterns across disparate data
- Translate complexity into a clear, unified picture
- Identify second-order effects others miss

**Prompt:**
```
I have these pieces of information / observations: [LIST THEM].
Help me synthesize:
1. What's the underlying pattern or theme across these?
2. What does this suggest about [market / customer / team / opportunity]?
3. What's the non-obvious conclusion?
4. What decision does this synthesis point toward?
```

---

### 6. Storytelling
Strategy that can't be communicated is strategy that won't get executed. Storytelling is the delivery mechanism.

- Translate complex strategy into simple, memorable narratives
- Tailor the message to the audience (board, team, customer)
- Use structure: situation → complication → resolution

**Prompt:**
```
I need to communicate [strategy / decision / change] to [AUDIENCE: board / team / investors / customers].
Help me:
1. Build a narrative using situation → complication → resolution.
2. Write the 3-sentence version (elevator pitch).
3. Write the 10-minute version (presentation outline).
4. Anticipate the 3 hardest questions and help me answer them.
```

---

### 7. Decisiveness
Strategic thinkers make decisions — even under uncertainty. Waiting for perfect information is itself a decision.

- Define the decision clearly: what's being chosen, by whom, by when
- Set a decision threshold — how much information is "enough"
- Own the decision and its consequences

**Prompt:**
```
I need to decide: [DECISION].
Key factors: [LIST WHAT'S KNOWN]
Uncertainties: [LIST WHAT'S UNKNOWN]
Help me:
1. Frame the decision — what are the real options?
2. What's the minimum information I need to decide confidently?
3. What's the cost of deciding wrong vs. deciding late?
4. Make a recommendation, with your reasoning.
```

---

### 8. Adaptability
Strategy is a hypothesis. The best strategists adapt when reality proves them wrong — without losing sight of the goal.

- Monitor leading indicators, not just lagging outcomes
- Build in explicit checkpoints to revisit assumptions
- Distinguish between changing strategy (good) and abandoning it (bad)

**Prompt:**
```
My original strategy was [DESCRIBE IT].
What I'm observing now is [NEW DATA / CHANGED CONDITIONS].
Help me:
1. Is this a signal to adapt, or noise to ignore?
2. What specifically should change — the goal, the approach, or the timeline?
3. How do I adapt without whipsawing the team?
4. What would need to be true for this strategy to be back on track?
```
