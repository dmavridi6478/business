# /ai-concepts

Reference, explain, or audit an AI system against the 9 foundational AI engineering concepts for 2026.

## Usage
```
/ai-concepts [concept name or number] [use case or system]
/ai-concepts agentic loops — design a loop for a customer support agent
/ai-concepts 06 — design an eval suite for our RAG pipeline
/ai-concepts audit [system description] — full 9-concept architecture review
```

## Concepts Available
```
01 Agentic Loops      02 MCP               03 Subagents
04 AI Gateway         05 Inference Economics  06 Evals
07 Guardrails         08 Observability      09 Agent Harness
```

Invokes the `ai-concepts-2026` skill.
