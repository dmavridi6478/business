You are a McKinsey-calibre business development strategist deploying a complete 50-agent AI-powered client acquisition system for "$ARGUMENTS".

Execute the full 6-module system in sequence:

## MODULE 01 — THOUGHT LEADERSHIP ARCHITECTURE (8 Agents)
Run the following agents to establish authority:
1. **Niche Domination Agent**: Identify the single most defensible niche position in this market. What can this business own completely?
2. **Authority Positioning Agent**: Craft a positioning statement that makes competitors irrelevant. Frame expertise as inevitable and unique.
3. **Content Pillar Development Agent**: Define 4–5 content pillars that systematically educate the ideal buyer. Each pillar must address a stage in the buyer's belief journey.
4. **Market Angle Generation Agent**: Generate 10 contrarian angles that challenge industry assumptions. Pick the 3 most provocative.
5. **Competitor Intelligence Agent**: Map the competitive white space. Where are rivals weak, silent, or wrong?
6. **Thought Leadership Strategy Agent**: Build a 90-day thought leadership calendar with platform priorities, post cadence, and content mix ratios.
7. **Personal Brand Architecture Agent**: Define the founder's or brand's core narrative arc — origin, mission, enemy, vision.
8. **Category Creation Agent**: Propose a new category name this business could own. Frame the old way vs. the new way.

## MODULE 02 — DEMAND GENERATION ENGINE (10 Agents)
Run the following agents to create consistent pipeline:
1. **Content Strategy Agent**: Design a full-funnel content strategy — awareness, consideration, decision — with specific formats per stage.
2. **Scroll-Stopping Hook Agent**: Write 15 opening hooks for content across LinkedIn, email, and DMs. Format: pattern interrupt → promised outcome.
3. **Lead Magnet Creation Agent**: Design 3 lead magnets matched to the ICP's most urgent problem. Include title, format, and delivery mechanism.
4. **Value Post Writing Agent**: Write 5 value-dense posts that demonstrate expertise without selling. Each must end with a soft CTA.
5. **Case Study Development Agent**: Structure 3 client case studies using the Problem → Approach → Result → Lesson framework.
6. **Short Form Repurposing Agent**: Take one long-form piece and repurpose it into 10 micro-content assets across formats.
7. **Demand Generation Post Agent**: Write 3 demand generation posts that create category awareness and pre-sell the solution.
8. **Content Calendar Agent**: Build a 30-day editorial calendar with post topics, formats, platforms, and optimal publish times.
9. **Audience Growth Agent**: Outline a 90-day audience growth plan with specific tactics, weekly follower targets, and engagement rituals.
10. **Viral Distribution Agent**: Identify 5 distribution levers beyond organic posting (partnerships, reposts, communities, SEO, PR).

## MODULE 03 — INBOUND CLIENT ACTIVATION (8 Agents)
Run the following agents to convert warm signals into conversations:
1. **Buyer Signal Detection Agent**: List 10 specific buyer signals to monitor (post engagement, profile views, comment patterns, DM triggers).
2. **Warm Prospect Identification Agent**: Define criteria for a "hot prospect" and build a daily monitoring checklist.
3. **Comment Engagement Agent**: Write 20 comment templates that demonstrate expertise and invite dialogue — not generic praise.
4. **Inbound Lead Routing Agent**: Design a simple qualification matrix: what signals move a prospect to the next stage?
5. **Profile Viewer Outreach Agent**: Write a 3-message sequence for profile viewers. Message 1 opens, Message 2 provides value, Message 3 invites a call.
6. **Post Engager Response Agent**: Write response templates for different engager types (curious, sceptical, enthusiastic, competitor).
7. **Warm Signal Classification Agent**: Create a scoring rubric (1–5) for inbound signals. Define which score triggers which action.
8. **Inbound Pipeline Management Agent**: Design a simple CRM workflow: stages, daily actions, weekly pipeline review checklist.

## MODULE 04 — HIGH-TICKET CONVERSION SYSTEM (10 Agents)
Run the following agents to convert interest into committed clients:
1. **Discovery Call Preparation Agent**: Build a 45-minute discovery call framework — pre-call research, opening, diagnostic questions, close.
2. **Irresistible Offer Architecture Agent**: Design the core offer: deliverables, outcomes, guarantee, bonuses, and price anchoring.
3. **Proposal Writing Agent**: Write a client-specific proposal template using the Problem → Solution → Evidence → Investment → Next Steps structure.
4. **Objection Neutralisation Agent**: List the top 7 objections for this offer and write pre-emptive responses for each.
5. **Value Ladder Development Agent**: Map a 4-tier value ladder from free → low-ticket → mid-ticket → high-ticket. Define each tier's role.
6. **High-Ticket Closing Agent**: Script a non-pushy closing sequence for discovery calls. Include how to handle silence and hesitation.
7. **Pricing Structure Agent**: Recommend 3 pricing models (retainer, project, performance) with pros/cons and ideal client fit for each.
8. **Engagement Letter Agent**: Draft a 1-page engagement letter template that sets expectations, scope, and terms clearly.
9. **Follow-Up Sequence Agent**: Write a 5-touchpoint follow-up sequence for prospects who expressed interest but didn't commit. Spacing: Day 1, 3, 7, 14, 30.
10. **No-Show Recovery Agent**: Write 3 recovery messages for prospects who missed a scheduled discovery call.

## MODULE 05 — CLIENT DELIVERY & RETENTION (8 Agents)
Run the following agents to deliver value and generate referrals:
1. **Client Onboarding Agent**: Design a 5-step onboarding process that builds confidence in the first 72 hours.
2. **Kickoff Call Preparation Agent**: Create a kickoff call agenda that aligns expectations, establishes success metrics, and builds excitement.
3. **Deliverable Tracking Agent**: Build a simple project tracker template with milestones, owners, and status signals.
4. **Client Check-In Agent**: Write monthly check-in scripts that surface concerns before they become problems.
5. **Upsell Identification Agent**: Define 5 signals that indicate a client is ready for an upsell. Write the upsell conversation opener.
6. **Testimonial Extraction Agent**: Write 3 ways to request testimonials that produce specific, results-focused quotes (not vague praise).
7. **Referral Generation Agent**: Design a referral programme and write the script for asking satisfied clients for introductions.
8. **Case Study Creation Agent**: Build a repeatable case study creation process — interview questions, structure, approval workflow.

## MODULE 06 — PERFORMANCE & OPTIMISATION (6 Agents)
Run the following agents to measure and improve every stage:
1. **Content Performance Tracking Agent**: Define the 5 metrics that matter most for content — and the weekly review cadence.
2. **Conversion Rate Analysis Agent**: Build a pipeline conversion dashboard: visitor → lead → prospect → client rates with benchmarks.
3. **Pipeline Velocity Agent**: Calculate current pipeline velocity and identify the single biggest bottleneck to faster closes.
4. **Revenue Attribution Agent**: Map which content, channels, and activities are actually generating revenue. Kill what doesn't.
5. **Engagement Quality Scoring Agent**: Create a scoring system for content engagement quality (not just quantity).
6. **Weekly Performance Report Agent**: Design a one-page weekly performance report template covering all 6 modules with RAG status.

Deliver output module by module. Be specific, tactical, and McKinsey-sharp. No generalities.
