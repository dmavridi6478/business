# /ooda

Apply the OODA Loop (Observe → Orient → Decide → Act) to a business crisis or fast-moving situation.

## Usage
```
/ooda [situation or crisis description]
```

## Example
```
/ooda Our main competitor just dropped prices 30% and we're losing deals
/ooda Customer churn spiked 40% this month and we don't know why
```

Invokes the `exec-problem-solving` skill → OODA Loop framework.
