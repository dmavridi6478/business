# /seo-backlinks

Run the full SEO backlink strategy system — competitor intelligence, gap analysis, outreach, digital PR, local links, and verification.

## Sub-commands
```
/seo-backlinks gap [website] vs [competitor1, competitor2]
/seo-backlinks competitor [your niche]
/seo-backlinks outreach [guest post / digital PR / local / collab]
/seo-backlinks verify [checklist]
/seo-backlinks toxic [website]
```

## Examples
```
/seo-backlinks gap mysite.com vs competitor1.com competitor2.com
/seo-backlinks competitor SaaS project management tools
/seo-backlinks outreach digital PR for a finance data report
```

Invokes the `seo-backlinks` skill.
