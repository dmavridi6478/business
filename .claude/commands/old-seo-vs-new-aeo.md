# Old SEO vs New AEO

Source: Naqui Shaikh (@Pierview.ai). A side-by-side contrast of the old keyword-ranking mindset against the newer discipline of making AI models trust and cite a brand. This repo's `ai-search-visibility` skill already covers the five-discipline SEO wheel (SEO/SXO/AEO/GEO/AIO), the 15-day action plan, and the four page-level AI-readability essentials (including `llms.txt`) in more depth — use this file as the quick before/after gut-check, that skill for the full audit and build plan.

| | Old SEO | New AEO |
|---|---|---|
| **Core belief** | Add schema and build AEO fixes for AI search visibility | Build an optimization strategy to make sure AI trusts your brand |
| **llms.txt** | Dump all pages into it | Curate only the required pages — save crawl budget, add only what's necessary |
| **Content strategy** | Keyword stuffing — write for every variation of prompts and topics | Entity-based content — write for topics, not keywords |
| **Observability** | Guess and check — no measurement strategy | Measure first — optimize with citation data and brand voice |
| **Platform focus** | Optimizing for ChatGPT and AI Overviews only — limited platforms | Multi-platform visibility — target more platforms, analyze which converts fastest |
| **Content style** | Targeting only E-E-A-T and answer-first content structure | Build content with proprietary data and original case studies |
| **Third-party platforms** | Building your AEO strategy focused only on your website | Building your AEO strategy focused on the platforms most cited by AI |
