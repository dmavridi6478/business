# /cs-qbr

Draft a Quarterly Business Review (QBR) outline for a customer account.

## Usage
```
/cs-qbr [account name] [quarter] [key metrics or context]
```

## Example
```
/cs-qbr Acme Corp Q3 2026 — 78% adoption, renewal in 60 days, upsell opportunity
/cs-qbr GlobalTech Q4 — missed activation target, strong exec relationship
```

Invokes the `customer-success-claude` skill → QBR prompt.
