# /aerialview

Generate an AI image prompt for a **bird's-eye aerial perspective** visualization.

## Usage
```
/aerialview [subject/scene] [optional: time of day, style]
```

## Example
```
/aerialview Taj Mahal gardens
/aerialview coastal luxury villa, golden hour, drone shot
```

Outputs a ready-to-paste prompt for Midjourney, DALL-E 3, Firefly, or Flux.
