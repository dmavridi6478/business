## THE 9 TECHNIQUES

### 1. Not-To-Do List (Tim Ferriss)
**What:** Write down everything you should stop doing — tasks that drain time without moving the needle.

**Why it works:** Leaders often focus on adding tasks. The real leverage is elimination. A not-to-do list clarifies what to protect your time FROM.

**How to apply:**
- List all recurring tasks from the past week
- For each: ask "Would anything bad happen if I stopped doing this for 30 days?"
- Move anything that passes that test to your Not-To-Do list
- Review weekly and defend it

**Prompt:**
```
I'm a leader in [role/industry]. Here are all my recurring tasks from last week: [LIST TASKS].
Apply the Not-To-Do List technique:
1. Which of these tasks are low-leverage or could be eliminated?
2. Which could be delegated without losing quality?
3. Write me a Not-To-Do List I can commit to for the next 30 days.
4. What's the estimated time I'd reclaim?
```

### 2. Focusing Question (Gary Keller)
**What:** Before every task block, ask: "What is the ONE thing I can do such that by doing it, everything else becomes easier or unnecessary?"

**Why it works:** Forces you to find the highest-leverage action — the task that unlocks or eliminates everything else.

**How to apply:**
- Ask the Focusing Question at the start of every day and every work session
- Do only that ONE thing first, before anything else
- Do not check email or messages before answering it

**Prompt:**
```
My current priorities are: [LIST YOUR PRIORITIES OR PROJECTS].
Apply the Focusing Question (Gary Keller):
1. What is the ONE thing I can do this week such that everything else becomes easier or unnecessary?
2. What is the ONE thing I can do TODAY?
3. What is blocking me from doing only that one thing?
4. How should I restructure my schedule around it?
```

### 3. Ivy Lee Method
**What:** At the end of each day, write the 6 most important tasks for tomorrow. Prioritise them 1–6. Start with #1 and don't move on until it's done.

**Why it works:** Simple, daily prioritisation removes decision fatigue in the morning. The constraint of 6 forces real prioritisation.

**How to apply:**
- Each evening: write tomorrow's 6 tasks in order of importance
- Next morning: start with task #1 — don't touch #2 until #1 is done
- Unfinished tasks move to the next day's list
- Repeat every day

**Prompt:**
```
Here is my full task list for tomorrow: [LIST ALL TASKS].
Apply the Ivy Lee Method:
1. Select the 6 most important tasks from this list.
2. Rank them 1–6 by importance and impact.
3. Explain why you ordered them this way.
4. What should I do with the tasks that didn't make the top 6?
```

### 4. Deep Work Blocks (Cal Newport)
**What:** Schedule uninterrupted 2–4 hour blocks for high-cognitive work. Protect them like external meetings.

**Why it works:** Complex, meaningful work requires sustained focus. Fragmented schedules destroy it. Blocking time signals its importance and prevents interruptions.

**How to apply:**
- Identify your peak cognitive hours (usually morning)
- Block 2–4 hours on your calendar — label it as a real meeting
- No email, Slack, or meetings during these blocks
- Use a shutdown ritual to end each block

**Prompt:**
```
My current weekly calendar looks like: [DESCRIBE OR PASTE SCHEDULE].
Apply Deep Work Blocks (Cal Newport):
1. Where are the best 2–4 hour windows for deep work this week?
2. What tasks qualify as deep work vs shallow work for my role?
3. How do I protect these blocks from meeting creep?
4. Design a week template with deep work scheduled in.
```

### 5. Two-Minute Rule (David Allen)
**What:** If a task takes less than 2 minutes, do it immediately. If it takes longer, schedule it.

**Why it works:** Small undone tasks pile up and create cognitive overhead. Clearing them instantly removes mental clutter without meaningful time cost.

**How to apply:**
- When a new task arrives: estimate time to complete
- Under 2 minutes → do it now
- Over 2 minutes → add to task list with a scheduled time
- Apply to email, requests, and decisions

**Prompt:**
```
Here is my current task inbox / email backlog: [LIST ITEMS].
Apply the Two-Minute Rule (David Allen):
1. Which items can be done in under 2 minutes? List them.
2. Which items need to be scheduled? For when?
3. Which items can be delegated or deleted?
4. After applying this rule, what does my cleared task list look like?
```

### 6. Task Batching (Cal Newport)
**What:** Group similar tasks together and do them in one dedicated block, rather than scattered throughout the day.

**Why it works:** Context-switching kills productivity. Batching reduces the startup cost of switching between different types of work.

**How to apply:**
- Identify categories of tasks: email, calls, reviews, writing, admin
- Assign a dedicated time block for each category
- Do ALL tasks in that category during its block — nothing else
- Common batches: email (2× per day), calls (afternoon), admin (Friday)

**Prompt:**
```
Here are the types of tasks I do regularly: [LIST TASK TYPES].
Apply Task Batching (Cal Newport):
1. Which tasks can be grouped into batches?
2. What's the ideal time of day for each batch?
3. How many times per day/week should each batch run?
4. Design a weekly task-batching schedule for my role.
```

### 7. Parkinson's Law
**What:** Work expands to fill the time available. Set shorter, artificial deadlines to force focus.

**Why it works:** Without time pressure, tasks stretch indefinitely. A tighter constraint forces prioritisation and decision-making within the task.

**How to apply:**
- Set a deadline shorter than you think you need
- Timebox specific tasks: "I'll finish this in 45 minutes"
- Use a visible timer (Pomodoro works well here)
- Done is better than perfect — ship, then refine

**Prompt:**
```
Here are tasks I tend to overextend: [LIST TASKS AND HOW LONG THEY USUALLY TAKE].
Apply Parkinson's Law:
1. What is the realistic minimum time needed for each task?
2. Set an aggressive (but achievable) timebox for each.
3. What's causing me to over-invest time in these tasks?
4. What "done" criteria should I set to stop at the timebox?
```

### 8. Weekly Review (David Allen)
**What:** A recurring weekly session to clear your inbox, review commitments, update your task system, and plan the coming week.

**Why it works:** Without a weekly review, tasks fall through cracks and priorities drift. The review is the maintenance ritual that keeps the whole system running.

**How to apply:**
- Block 60–90 minutes every Friday (or Sunday)
- Clear all inboxes (email, notes, physical)
- Review all active projects and next actions
- Capture anything new; delete anything done
- Plan the coming week: what are the big 3 outcomes?

**Prompt:**
```
Help me run my Weekly Review (David Allen).
My current projects: [LIST PROJECTS]
My open loops and pending items: [LIST]
Last week's highlights: [WHAT GOT DONE]
Run the Weekly Review:
1. What needs to be captured or clarified?
2. What projects have no next action — what should the next action be?
3. What can be deleted, delegated, or deferred?
4. What are my top 3 outcomes for next week?
```

### 9. Calendar Audit (David Allen)
**What:** Review every recurring meeting and commitment on your calendar. Delete, delegate, or shorten anything that doesn't earn its time.

**Why it works:** Calendars accumulate meetings that outlive their purpose. A calendar audit is a time-reclamation exercise that leaders rarely do but always need.

**How to apply:**
- Export or review your full calendar for the past 4 weeks
- For every recurring meeting: does this need to exist? Does it need me?
- Shorten meetings that run longer than needed (default to 30 min)
- Decline or delegate meetings where your presence isn't essential

**Prompt:**
```
Here are my recurring meetings and calendar commitments: [LIST ALL RECURRING ITEMS WITH DURATION AND FREQUENCY].
Apply the Calendar Audit (David Allen):
1. Which meetings can be eliminated entirely?
2. Which can I delegate or send a representative to?
3. Which should be shortened? By how much?
4. What time would I reclaim if I made all these changes?
5. What should I replace that time with?
```
