# /billboard

Generate an AI image prompt for a **billboard advertisement mockup** product visualization.

## Usage
```
/billboard [product name] [optional: brand colors, city, mood]
```

## Example
```
/billboard Nescafé Gold
/billboard Nike Air Max, New York Times Square, night, neon
```

Outputs a ready-to-paste prompt for Midjourney, DALL-E 3, Firefly, or Flux.
