# /ai-governance

Audit or build an enterprise AI governance program across all 6 layers.

## Usage
```
/ai-governance audit [organization/system]
/ai-governance layer [1-6] [organization]
/ai-governance policy [layer name]
```

## Examples
```
/ai-governance audit our AI deployment across the marketing and ops teams
/ai-governance layer 3 — security and access review
/ai-governance policy compliance and audit for a GDPR-regulated company
```

Invokes the `ai-governance-layers` skill.
