# Claude Prompts for Founders

Source: @aisimplified23, "71 Claude Prompts For Founders." 70 distinct prompts were captured across the uploaded images (organized into 8 categories below, matching the title's count almost exactly — 2 cards in category E were exact on-screen duplicates and are listed once here); the ~1 remaining wasn't shown in this source and isn't guessed at here. Every prompt is fill-in-the-blank and copy-paste ready — replace the bracketed placeholders and paste directly into Claude.

Distinct from this repo's `claude-founder-prompts` (11 one-line *meta*-prompting techniques like "argue the other side of this") — these are actual ready-to-use content templates for marketing/sales copy.

## A. Ads & Video Scripts (8)

```
Write 3 ads for my free live training on [topic] for [audience]. Outcomes:
[2-3]. Date: [x]. Open on the problem or outcome, two sentences on the
training, CTA to register. Under 110 words each.
```
```
Write a talking head video ad script for [offer]. Audience: [x]. Length:
[30/45/60s]. Speaker: [x]. Natural spoken dialogue, hook in 5 seconds, the
offer introduced not announced, one instruction.
```
```
Write a 45-60 second on-camera testimonial script. Client: [role, before,
what they did, result]. Open with the result, build back to the start,
close to a viewer in their old position. Natural speech.
```
```
Write a creative brief for a video ad for [offer]. Audience: [x].
Objective: [x]. Cover the hook and why it works, tone, key messages in
priority order, the response wanted, and the CTA. Under 300 words.
```
```
Write 2 ad variants for [offer] taking genuinely different angles. A leads
with [angle, e.g. the problem]. B leads with [a different angle].
Audience: [x]. Same length, under 100 words, same CTA.
```
```
Write 3 ads for [event] opening [date]. What it is: [x]. Who for: [x].
Real reason for the deadline: [x]. Best result: [name, number]. Open on
the outcome, then the event, the deadline, a CTA. Under 110 words.
```
```
Write 2 brand awareness ads introducing me to a cold audience of [x]. What
I do: [x]. One credibility result: [name, number]. What I want them to
associate with me: [x]. No hard CTA. Under 100 words each.
```
```
Write 3 ads for my free [community/challenge]: [name, description].
Audience: [x]. What joining gives them: [x]. Next step: [x]. Describe what
they'll be able to do, not what's inside. Under 100 words each.
```

## C. Sales Page Copy Sections (8)

```
Write the "what you get" section for [offer]. Included: [list]. For each,
2-3 sentences on what it is, what the buyer does with it, and what becomes
possible. Flowing prose, not a feature list.
```
```
Write a 200-word about section for my sales page. Name: [x]. Credentials
with numbers: [x]. Client examples: [x]. Don't open with "Hi, I'm" — open
with a result or a moment. First person.
```
```
Write a social proof section from these results: [Client 1: role, start,
action, result] [Client 2] [Client 3]. One setup line, then each as 3-5
sentences opening with the result. No invented quotes.
```
```
Write an FAQ section for [offer]. Questions: [5-8 real ones in your
prospects' words]. Answer each in 2-4 sentences. Be direct, name genuine
limitations, no sales copy disguised as answers.
```
```
Write an objection handling section for [offer]. Objections in prospects'
words: [3-4]. Acknowledge each, answer it specifically, and where you can
name a client who had the same doubt. Prose.
```
```
Write price anchoring copy for [offer] at [price]. Real results: [name,
result, number]. Frame the price against the value of the outcome or the
cost of staying stuck. No false anchors. Under 150 words.
```
```
Write guarantee copy for [offer]. My guarantee: [describe exactly]. State
plainly what the buyer is protected against and what they must do to claim
it. Never imply more cover than exists. Under 120 words.
```
```
Write 5 CTA blocks for [offer]. Each: button text, one line above
reinforcing the decision, one line below answering the main hesitation.
Vary across outcome, urgency, exclusivity and reassurance.
```

## H. Founder Story, Positioning & Sales Page Core (8)

```
Structure my founder story: [background, turning points, results]. Cover
where I was, what changed, what I did differently, the result with
numbers, and how it shapes my work today. Under 300 words.
```
```
Act as a positioning strategist. Background: [x]. Audience: [x]. Find 5
areas where I could build proprietary frameworks. For each: why my angle
is distinctive, the gap it fills, and its rough shape.
```
```
Write 10 sales page headlines for [offer]. Audience: [x]. Promise:
[outcome + timeframe]. Under 15 words each, led by a specific outcome. No
vague adjectives. Then name the strongest 3 and why.
```
```
Write a value proposition for [offer] around the buyer's 3 biggest
outcomes. For each: state it with a number, explain what it means day to
day, and anchor it in a real client result.
```
```
Write the problem section of my sales page for [offer]. Their situation
before me: [x]. Their frustrations, in their words: [x]. Make them feel
precisely understood, not lectured. Under 200 words.
```
```
Write the solution section of my sales page for [offer]. My approach:
[how it works, why it beats the usual attempts]. Explain the mechanism,
not just the outcome. Under 200 words.
```
```
Write the "this is for you if" section for [offer]. Ideal client: [role,
situation, what they've tried]. Five full sentences, each a situation or
belief so specific the right reader stops.
```
```
Write the "this is not for you if" section for [offer]. Four honest
sentences on who won't get results and why. Situations and mindsets, not
demographics. Direct, never dismissive.
```
