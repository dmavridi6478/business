# /cs-onboarding

Build a 90-day onboarding plan for a new customer.

## Usage
```
/cs-onboarding [customer name] [company type] [product] [use case]
```

## Example
```
/cs-onboarding TechStartup Inc — B2B SaaS, using our analytics platform for sales reporting
```

Invokes the `customer-success-claude` skill → Onboarding Plan prompt.
