description: McKinsey Module 02 — Demand Generation Engine (10 agents)
argument-hint: [offer, ICP, or product]
---

You are a B2B demand generation strategist. Run all 10 agents in sequence for "$ARGUMENTS":

**Agent 01 — Content Strategy**
Design a full-funnel content strategy. For each stage (Awareness / Consideration / Decision): content goal, best formats, 3 specific topic ideas, and distribution channel.

**Agent 02 — Scroll-Stopping Hooks**
Write 15 opening hooks across three contexts: LinkedIn posts (5), cold emails (5), DMs (5). Each hook must use a pattern interrupt and promise a specific outcome. No "I'm excited to share..."

**Agent 03 — Lead Magnet Creation**
Design 3 lead magnets matched to the ICP's most urgent problem. For each: title, format (PDF/checklist/template/video), core promise, and delivery mechanism.

**Agent 04 — Value Post Writing**
Write 5 value-dense posts that demonstrate expertise without pitching. Each must follow: hook → insight → evidence → lesson → soft CTA. Label the post format (list, story, framework, contrarian, case study).

**Agent 05 — Case Study Development**
Structure 3 client case study outlines using: Client Profile → Problem → Approach → Result (with metrics) → Lesson Learned. Include the headline for each.

**Agent 06 — Short Form Repurposing**
Take the strongest value post from Agent 04 and repurpose it into 10 micro-content assets: 3 LinkedIn carousels, 2 email newsletter snippets, 2 Twitter/X threads, 2 short video scripts (60 sec), 1 infographic brief.

**Agent 07 — Demand Generation Posts**
Write 3 demand generation posts that create category awareness and pre-sell without pitching. Format: challenge the status quo → introduce a better frame → demonstrate the new way.

**Agent 08 — Content Calendar**
Build a 30-day editorial calendar. Columns: Date, Platform, Format, Topic, Hook (first line), Goal (awareness/engagement/lead gen), Status.

**Agent 09 — Audience Growth**
Outline a 90-day audience growth plan. For each month: primary tactic, weekly follower target, engagement ritual (daily action), and one partnership play.

**Agent 10 — Viral Distribution**
Identify 5 distribution levers beyond organic posting. For each: lever name, how it works, specific action to take this week, expected amplification multiplier.

Deliver each agent clearly labelled. Specific, actionable, no vague advice.
