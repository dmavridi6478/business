# Personal AI Automation Tool Stack

Source: @usama_gujjar_official (TikTok), "My personal AI Automation Tool
Stack" — a 4-category stack (Systems, Growth, The Engine, Content), each
tool with its named use cases. All commercial SaaS tools named as-is; none
require cloning.

## Systems
| Tool | Used for |
|---|---|
| Google Calendar | Time blocking, event reminders, auto scheduling |
| Obsidian | Connected notes, research vault, idea repository |
| Fireflies | Meeting notes, action items, call summaries |
| Notion | Habit trackers, content calendar, second brain |

## Growth
| Tool | Used for |
|---|---|
| Apify | Scrape leads, pull comments, track competitors |
| Clay | Lead enrichment, list building, email discovery |
| HeyReach | LinkedIn DMs, connection requests, follow-ups |
| Smartlead | Cold email campaigns, inbox rotation, auto follow-ups |

## The Engine
| Tool | Used for |
|---|---|
| Claude Code | Build AI agents, automate lead gen, run your content system |
| n8n | Connect your apps, auto-post content, trigger tasks on autopilot |
| Cursor | Build a website, edit code fast, ship small apps |
| Lovable | Idea → app, landing pages, quick prototypes |

## Content
| Tool | Used for |
|---|---|
| Claude | Script writing, long-form content, content strategy |
| ElevenLabs | Reel voiceovers, dubbing, cloned voice |
| Wispr Flow | Voice notes → text, draft by talking, fast captions |
| Gamma | Carousels, pitch decks, one-pagers |
