# /yt-seo

Build a complete YouTube SEO and growth strategy for your channel.

## Usage
```
/yt-seo [your niche] [current subscribers] [avg views per video]
```

## Example
```
/yt-seo personal finance, 0 subscribers, 0 views
/yt-seo AI productivity, 1200 subscribers, 400 avg views
```

Invokes the `yt-faceless-channel` skill → SEO & Growth Strategy prompt.
