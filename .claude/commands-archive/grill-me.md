Use the skill `prompt-writing-9-skills` (step 02). Input: "$ARGUMENTS".

1. Ask exactly one question at a time, using `AskUserQuestion` when the answer is a choice, plain text otherwise. Start with the biggest unknown (goal, audience, success measure, constraints), not a detail.
2. After each answer, restate in one line what is now settled. Do not move on while an answer is vague ("good", "soon", "some").
3. Stop when goal, audience, inputs, constraints, output format and success check are all concrete, or after 12 questions, whichever is first.
4. Finish with the settled spec in one plain-text block and the list of anything still open.
