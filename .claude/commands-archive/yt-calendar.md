# /yt-calendar

Build a 30-day content calendar for your faceless YouTube channel.

## Usage
```
/yt-calendar [your niche] [videos per week]
```

## Example
```
/yt-calendar personal finance for millennials, 3 videos/week
/yt-calendar AI tools tutorials, 2 videos/week
```

Invokes the `yt-faceless-channel` skill → Content Calendar prompt.
