# /yt-monetize

Build a realistic YouTube monetization roadmap from 0 subscribers to income.

## Usage
```
/yt-monetize [your niche]
```

## Example
```
/yt-monetize personal finance for millennials
/yt-monetize AI tools and automation tutorials
```

Invokes the `yt-faceless-channel` skill → Monetization Roadmap prompt.
