# /yt-niche

Find and validate the ideal faceless YouTube niche for your profile.

## Usage
```
/yt-niche [your interests/skills] [hours per week] [budget]
```

## Example
```
/yt-niche finance and investing, 10 hours/week, $100/month budget
/yt-niche AI tools and productivity, 5 hours/week, $50/month
```

Invokes the `yt-faceless-channel` skill → Niche & Channel Strategy prompt.
