1. Go to claude.ai, sign in or create an account.
2. Starter prompt: `I want to build an AI agent. Ask me the right questions one by one to set it up. I'm new to this, so keep it simple and beginner-friendly.`
3. Add skills (optional but powerful): Skills section, enable Web Search, File Reader, Code Interpreter.
4. Connect your tools: Connectors section; Gmail, Google Drive, Notion, Slack or custom APIs; click, authorize, connect.
5. Set up your agent: name, description and goal, e.g. "Help me to manage my emails and summarize important messages today."
6. Configure settings: behaviour, response style, permissions (what it may use and access).
7. Test with real tasks, e.g. "Search for the latest AI news and give me a 3-point summary."
8. Make it live: save the agent and use it in Claude or the web app.
9. Improve over time: tweak the prompt, add skills or tools.
10. Enjoy.
