# Turn any AI idea into a real workflow
1. **Start with the problem** - a repetitive, slow, expensive or error-prone task (example: 2 hours a week researching competitors).
2. **Define the desired outcome** (example: a weekly report with new features, pricing changes and key insights).
3. **Set the trigger** - scheduled time, new email, new file, Slack message, system event, manual request.
4. **Define the inputs** - documents, URLs, data from tools, business rules, previous examples, other context.
5. **Map the AI work** - research, analyse, process (filter and organise), create, review.
6. **Connect the tools** - web search, Google Drive, Notion, Slack, GitHub, database, APIs/MCP.
7. **Add review and guardrails** - auto-allowed tasks (research, analysis, drafting); human approval for important actions; safety rules (what AI cannot do); quality checks.
8. **Define the final output** - format, audience, frequency, success criteria.
**Formula:** Problem, Outcome, Trigger, Input, Process, AI, Tools, Guardrails, Review, Output.
**Example (content):** trigger = new topic in a spreadsheet; input = topic, audience, brand guidelines, examples; AI = research, best angle, hooks, draft, fact-check, QA; tools = web search, Notion, Drive, Slack; human review; output = final post, scheduled; feedback = track performance, improve.
**Ladder:** AI idea -> workflow (steps, tools, rules) -> automation (trigger) -> AI agent (executes steps) -> AI system (continuous improvement). "Do not just use AI. Build workflows that create real results."
