## 3. Solopreneur four (@dotdevs)
Notion (one place for everything), Stripe (get paid without building billing), Resend (email that lands), Vercel (ship the same day).

## 4. SEO five (@entrp0)
Search Console (what Google indexed), SERPtag (rank tracking), PageSpeed Insights (slow pages), AnswerThePublic (content ideas from searches), AlsoAsked (related questions). Search Console and PageSpeed are free. Here you also have **Ahrefs and Semrush connected**, which cover rank tracking and keyword research; add the free tools first.

## Pick rule (my view)
A list of 55 tools is a map of the market, not a stack. Start from the job, keep one tool per job, and replace a tool only when you can name the cost it saves. For this business: assistant (Claude), CRM (HubSpot), enrichment (Clay), SEO (Ahrefs + Search Console), design (Canva, Figma), automation (Zapier). Everything else needs a stated reason.

Command: `/ai-stack <job>`. Related: `ai-tools-50-map`, `ai-marketing-sales-tools-60`, `connector-allowlist` rules in `docs/ai-os/rules/`.
