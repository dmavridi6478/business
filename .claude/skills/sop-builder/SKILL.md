# SOP Builder

Turn any repeated task into a complete Standard Operating Procedure with automation opportunities.

## Prompt

```
Act as my process documentation specialist. I'll explain a task I perform repeatedly. Interview me until you understand the process well enough for another person to complete it without my involvement. Turn it into a practical SOP containing: purpose, trigger, inputs, tools, exact steps, decision points, quality checks, common mistakes, expected output, and escalation rules. Then identify which parts could be automated with AI or software.
```

## When to Use

Invoke `/sop-builder` when you want to document a process so someone else (or a future AI agent) can execute it without your involvement, and to identify automation opportunities.

## Usage

1. Invoke the skill
2. Paste the prompt into Claude
3. Describe the task you want to document
4. Claude will interview you until it has enough detail, then produce the full SOP
