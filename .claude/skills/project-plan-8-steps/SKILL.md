# 8 steps to write a project plan

Source: a labelled circular infographic. Each step's one-line description is from it; the output fields and the check are added.

| # | Step | Source description | Output fields |
|---|---|---|---|
| 1 | Define project objectives | State what the project aims to achieve, including measurable goals and expected outcomes | Goal sentence; 1-3 measurable targets with date |
| 2 | Identify stakeholders | List sponsors, customers, team members and key people who influence success | Table: name, role, influence, what they need |
| 3 | Define scope | Specify what is included and excluded to avoid scope creep | In-scope list; **out-of-scope list**; change rule |
| 4 | Create a work breakdown structure (WBS) | Break the project into smaller tasks, deliverables and work packages | Tree to work-package level; each with an owner |
| 5 | Develop the schedule | Timelines, milestones, dependencies and deadlines (Gantt or calendar) | Milestone list; dependencies; critical path |
| 6 | Allocate resources and budget | Team members, equipment, materials, estimated costs | Resource table; budget by work package; contingency % |
| 7 | Identify risks | Analyse potential risks, assess impact, prepare mitigation | Register: risk, likelihood, impact, mitigation, owner |
| 8 | Establish monitoring and communication plans | Reporting methods, communication frequency, KPIs, progress tracking | Cadence table; KPI list; escalation path |

## Order rule

Do the steps in order. A schedule (5) written before a WBS (4) is a guess; a budget (6) before scope (3) is a wish. If a later step reveals a gap, go back and change the earlier step, do not patch the later one.

## Completeness check (all must be yes)

1. Every objective has a number and a date.
2. Every stakeholder has a stated need.
3. The out-of-scope list is not empty.
4. Every work package has one owner.
5. Every milestone has a date and a dependency.
6. Budget lines sum to the total; contingency is stated.
7. Top 3 risks each have an owner and a trigger.
8. A named person reads the KPIs on a stated day.

## Output

A one-to-two page plan in the table order above, then the check with yes/no per line and the failing lines first. Do not invent figures: unknown values are written "TBC - owner - date to confirm".
