# GitHub profile toolkit (@code_debug)
1. **Skill Icons** (skillicons.dev) - icon strip for your tech stack in a README.
2. **readme.so** - visual editor for README pages, no coding.
3. **ProfileMe.dev** - all-in-one developer profile (work, skills, achievements, links).
4. **Shields.io** - custom badges for project details, stats and tools.
5. **OctoProfile** - personalised, professional profile README (the card shows only a search box; URL not verified).
Workflow: create the repo named exactly like your username, put README.md in it, draft in readme.so, add icons and badges, keep it to one screen. URLs for tools 2, 3 and 5 are from the card names, not the slides; check them before pasting data anywhere.
