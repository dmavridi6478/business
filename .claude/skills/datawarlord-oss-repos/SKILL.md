## Repos

### #01 — ESP32-BlueJammer
**Wireless Security Research**
`github.com/EmenstaNougat/ESP32-BlueJammer`

An ESP32 and nRF24-based wireless security research project for experimenting with interference across 2.4 GHz communications.

Tags: `HARDWARE` `SECURITY`

```bash
git clone https://github.com/EmenstaNougat/ESP32-BlueJammer
```

### #02 — DSPy
**Prompt Engineering for AI Systems**
`github.com/stanfordnlp/dspy`

A framework from Stanford NLP for programming and optimizing AI systems instead of manually refining prompts. Great for RAG pipelines, agents, and classifiers.

Tags: `AI` `FRAMEWORK`

```bash
git clone https://github.com/stanfordnlp/dspy
pip install dspy
```

---

### #03 — auto-editor
**Automatic Video and Audio Editing**
`github.com/WyattBlue/auto-editor`

A command-line video and audio editor that can automatically detect and remove silent or uninteresting sections from recordings.

Tags: `VIDEO` `EDITING` `AUTOMATION` `PRODUCTIVITY` `CREATORS`

```bash
git clone https://github.com/WyattBlue/auto-editor
pip install auto-editor
# Usage: auto-editor my_clip.mp4
```
