## Map to this repo
- Orchestrators and teams already here: `governed-marketing-team`, `ultimate-marketing-dept`, `forge-marketing-team`, `ai-marketing-team`, `one-person-marketing-team-map`, `claude-revenue-system-58-agents`, and the gate agent `brand-reviewer`.
- Use the department split as a checklist; add an agent only where no skill exists for that job.

## Cautions
- **[Certain]** Fifty agents is an org chart, not a result: no output quality, cost or conversion data is shown.
- **[Likely]** More than a handful of sub-agents raises cost and coordination errors; start with the strategy, content and QA lines and keep a human approval before anything publishes (`os-approval` pattern).
