# 8 swaps (slide numbers 2-9 of 9; slide 1 is the cover)
| Paid | Swap | Slide claim | Stated trade-off |
|---|---|---|---|
| Wispr Flow | Handy | free, open source, offline dictation in any text field | - (best for dictation) |
| Granola | Hyprnote | local-first meeting notes, transcript + summary, no cloud | setup is less invisible |
| Perplexity Pro | Perplexica | open-source cited web search, self-hosted; bring a model and search provider | you run it |
| Cursor | Void | open-source editor, local-model support, code stays on machine | younger product, fewer edges polished |
| Midjourney | ComfyUI + Krea 2 | local workflows, node control, free tier | GPU + steeper learning curve |
| ChatGPT Plus | Open WebUI + Ollama | self-hosted, private by default, any model | frontier quality may still need an API |
| Grammarly Premium | LanguageTool | open-source core, 25+ languages, self-host option | less generative rewriting |
| Zapier | Activepieces | open source, self-hosted, AI-ready, unlimited workflows | smaller integration catalog |
Not verified here: repo URLs, licences, current maintenance, "free" (some have paid hosted tiers), hardware needs (ComfyUI and local LLMs need a capable GPU). Before cancelling anything: run both for two weeks, count what you actually used, check the licence (AGPL/GPL matters if you serve others). Use `/self-host-swap`.
