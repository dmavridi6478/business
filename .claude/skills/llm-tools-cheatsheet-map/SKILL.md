# LLM Tools Cheatsheet (logo map)

Source: an animated GIF named "Deploy AI agents", but the content is a static map titled **"LLM TOOLS CHEATSHEET"** with a brain-and-LLM illustration; the animation only moves the connector dots. Footer: "Follow for more insights on Tech/AI Content and Tech Personal Branding". **It contains no deployment steps**, so no agent was built from it.

| Group | Description on the map | Tools shown |
|---|---|---|
| General-purpose LLM providers | Used for training, fine-tuning and deploying LLMs | Claude, OpenAI, Gemini, LLaMA, Mistral, Grok, DeepSeek, Cohere, AI21 Labs |
| AI agent and multi-agent systems | Orchestrate tasks, agents, memory and planning | AutoGen, CrewAI, Superagent, CAMEL-AI, MGX, Manus, AgentVerse, LangGraph, AutoGPT |
| LLM application frameworks | Build full-stack LLM apps with memory, chains and tools | LangChain, LlamaIndex, Haystack, OpenLLM, Semantic Kernel, DSPy, Guardrails AI |
| Prompt engineering tools | Craft, store, evaluate and manage prompts | PromptLayer, Promptable, Langfuse, ChainForge, PromptPerfect, PromptTools |
| Vector databases | Store embeddings for RAG and semantic search | FAISS, ChromaDB, Pinecone, Weaviate, Redis, Qdrant, Milvus |
| No-code and low-code AI builders | Build LLM apps without writing heavy code | Flowise, Langflow, n8n, Replit, Cursor, Lovable, Chatbase, Relevance AI, v0 |

Notes: the logos for "kernel" and "MGX" were read from small marks and are my best reading; Cursor, Replit, Lovable and v0 are AI coding tools more than workflow builders. Licences and prices were not checked. For choosing, see `ai-ecosystem-map`, `oss-ai-alternatives`, `rag-pipeline-architecture` and `vector-index-tuning`.
