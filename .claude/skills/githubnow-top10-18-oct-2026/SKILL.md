## The three detailed in the video
- **anthropics/claude-plugins-official** (41.6k stars): the official directory of plugins. Read the plugin's code before installing; "official directory" is the narration's claim and a listing is not a security review.
- **MadsLorentzen/ai-job-search** (50.1k stars): a Claude Code job-search framework (scrape postings, evaluate, tailor CV, cover letters, interview prep). Its README says it is independent of Anthropic and has no token or sponsorship program. **Job applications go to real employers; keep a human review before anything is sent, and be honest with employers about AI use.** Related skill `job-hunt-hq`, `job-application-5-prompts`.
- **debpalash/VoiceStudio** (73.0k stars on the video): open-source voice cloning, voice design, dubbing, dictation, transcription and audiobooks, with a local API and MCP. **Voice cloning without consent is a legal and ethical risk** (impersonation, fraud); clone only your own voice or with written consent. AGPL-3.0 applies if you modify and host it.
