# Site Tusk repo cards (5)

Source: a "N / 7" carousel; five repo slides were in the upload. Each shows the README and one plain sentence. The like and save counts on the slides are TikTok interface text, not data about the repos.

| Repo | Licence | What it is | Catch |
|---|---|---|---|
| trimstray/the-book-of-secret-knowledge | MIT | A collection of cheatsheets, one-liners, tools and guides for sysadmin, DevOps, networking and security | A reading list; run any one-liner on a test machine first |
| github/gitignore | CC0-1.0 | GitHub's collection of `.gitignore` templates for languages and frameworks | Templates are starting points; add your own secrets and build folders |
| ghostfolio/ghostfolio | AGPL-3.0 | Open-source wealth management for tracking stocks, ETFs and crypto; the README links a hosted "Premium" tier | Self-hosting means you secure and back up your financial data; not investment advice |
| StevenBlack/hosts | MIT | Generates a hosts file that blocks ad, malware and optionally adult or social domains | It edits a system file: back it up, expect some sites to break, and prefer a DNS-level blocker (see `homelab-pihole-dns`). | nextcloud/server | AGPL-3.0 | Self-hosted file, calendar and data platform | You run updates, backups and security; compare with the options in `self-hosted-docker-stack` and `ms365-free-alternatives` |
