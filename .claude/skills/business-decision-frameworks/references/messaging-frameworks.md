# Messaging & Communication Frameworks

Source: reviewed from an uploaded infographic — "Mastering ChatGPT"
(smarterwithai.news). Six short-form frameworks for structuring copy,
goals, interview answers, and situational analysis — distinct from this
skill's other reference files, which cover *prioritization* (RICE,
MoSCoW) and *product-decision* (CIRCLES) structuring, not messaging or
goal-framing.

## AIDA — copywriting/ad structure

**Attention → Interest → Desire → Action.** Best for: emails, ads,
landing-page copy. Grab attention first (a hook, a surprising fact), build
interest (relevance to the reader), create desire (the specific benefit),
then a single clear call to action. Skipping straight to Action without
earning Interest/Desire first is the most common failure mode.

## PAS — Problem / Agitate / Solution

Best for: product copy, sales pages. State the problem plainly, agitate it
(make the cost of *not* solving it concrete and felt), then present the
solution as the natural resolution. PAS is more confrontational than AIDA
and works best when the reader already has the problem but hasn't felt
its full weight yet.

## FAB — Features / Advantages / Benefits

Best for: sales, product one-pagers. For each feature, state the
advantage it gives (what it does better than the alternative) and the
benefit to the specific reader (what that advantage means for *them*).
A features list without the Advantage/Benefit translation is the classic
failure mode — readers don't buy features, they buy what features do for
them.

## STAR — Situation / Task / Action / Result

Best for: interview answers, case studies, performance reviews. Set the
Situation (context), state the Task (what needed to happen), describe the
Action (what was actually done, specifically — "I," not "we," for an
individual interview answer), and close with the Result (a measurable
outcome, or the closest honest approximation of one). A STAR answer that
skips a quantified Result is markedly weaker than one that has one.

## SMART — goal-setting

**Specific, Measurable, Achievable, Relevant, Time-bound.** The
best-known goal-setting checklist — use it to pressure-test a stated goal
before committing resources to it, not as a creative framework in itself.
A goal that fails "Measurable" (no way to know if it was hit) or
"Time-bound" (no deadline) isn't a goal yet, just an intention.

## SWOT — strategic analysis

**Strengths, Weaknesses, Opportunities, Threats.** Strengths/Weaknesses
are internal (within the org/product's control); Opportunities/Threats
are external (market, competitors, environment). The common failure mode
is treating all four quadrants as equally weighted brainstorm buckets
instead of using the internal/external split to actually inform strategy
— e.g. matching a Strength to an Opportunity, or naming which Weakness
makes a specific Threat dangerous.

## How to use these

1. Pick the one framework that matches the actual deliverable — copy
   (AIDA/PAS/FAB), an interview or case-study answer (STAR), a goal
   (SMART), or a strategic scan (SWOT). These are not interchangeable;
   using SWOT to write ad copy or AIDA to set a goal produces a weak
   result because the framework doesn't match the task.
2. Apply the framework's structure to the user's actual content — don't
   just output the acronym's letters as generic labels with nothing under
   them.
3. Same caveat as this skill's other reference files: these are
   condensed-infographic summaries, accurate but shallow. For high-stakes
   copy (a funded campaign, a board-facing SWOT), treat this as a starting
   scaffold and verify structure/nuance against a primary source before
   relying on it.
