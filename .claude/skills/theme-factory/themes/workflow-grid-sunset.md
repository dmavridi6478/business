# Workflow Grid Sunset

A peach-to-coral gradient background with a dense grid of small pastel-tinted icon tiles, a two-tone orange/pink headline, and a bold coral CTA bar. Built for showing many small items (50–100) at once without feeling like a spreadsheet.

Source: sampled from "The Complete Claude + n8n Sales System — 100 workflows" (uploaded lead-magnet infographic). Colours approximated.

## Color Palette

- **Peach Top**: `#FFE0C5` → **Coral Bottom**: `#FFC9B8` - Page gradient
- **Signal Orange**: `#FF560C` - Headline word 1 ("Claude")
- **Hot Pink**: `#FF2351` - Headline word 2 ("n8n"), accents
- **Ink**: `#1A1C28` - Body text, tile labels
- **Tile White**: `#FFFFFF` - Tile background
- **Tile tints** (rotate across tiles): Mint `#E2FDEA`, Lilac `#F1E9FF`, Sky `#E9F3FF`, Butter `#FFF6D9`, Blush `#FFEAF0`
- **CTA Coral**: `#E14423` - Bottom call-to-action bar

## Typography

- **Headers**: Aptos Display Black, tight tracking (source: a rounded heavy grotesk)
- **Body Text**: Aptos Semibold, small, for tile labels

## Best Used For

Large tool/workflow catalogs (50–100 items), "complete system" roundups, capability grids, lead-magnet cover pages, dense reference posters.
