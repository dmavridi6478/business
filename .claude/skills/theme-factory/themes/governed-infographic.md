# Governed Infographic

A cream editorial infographic with a heavy black headline and colour-coded layer bands (orange, green, blue, purple, orange). Reads as a serious operating model rather than a social graphic.

Source: sampled from an uploaded infographic ("The Governed Marketing Team", prosp / Claude). Colours approximated from the image.

## Color Palette

- **Paper**: `#F3F0EB` - Page background
- **Card White**: `#FFFFFF` - Side columns and cards
- **Ink**: `#070705` - Headline and body text
- **Routing Orange**: `#E2582B` - Layer 1 border/number (tint `#FFF5E8`)
- **Working Green**: `#2F8F4E` - Layer 2 (tint `#F4FFFA`)
- **Gate Blue**: `#2A45D0` - Layer 3 (tint `#F6F9FF`)
- **Control Purple**: `#6A36C9` - Layer 4 (tint `#FDFBFF`)
- **Foundation Orange**: `#E2582B` - Layer 5 (tint `#FCF8F7`)

Each layer: 2 px rounded border in the layer colour, filled number tile top-left, italic layer name top-right in the same colour, three-column bullet grid with round bullets in the layer colour.

## Typography

- **Headers**: Aptos Display Black (source uses a heavy condensed serif, e.g. DM Serif Display / Playfair Display Black)
- **Body Text**: Aptos

Operating models, governance frameworks, process architectures, "who does what" explainers, LinkedIn document posts, one-page strategy summaries for leadership.
