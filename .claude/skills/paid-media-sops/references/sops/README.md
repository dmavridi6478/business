# Paid Media Operating System — SOP Library

## What This Is

A complete framework for managing paid media accounts across any platform. Built around one foundational idea: there are **five atomic metrics** (Spend, CPM, CTR, CVR, AOV) that govern all paid media performance. Every other metric is derived from these five. Diagnose the five, and you can solve any problem in any ad account.

These SOPs cover everything from how to read data and diagnose performance, to how to manage creative, measure incrementally, and think about profit instead of ROAS.

## Core Principles

- **The job is incremental contribution margin, not ROAS.** Every ad decision ties back to profit.
- **MTA is only 40% of the picture.** Combine with post-purchase surveys and causal measurement.
- **Optimize weekly, not daily.** Respect the learning phase. Follow the budget change framework. Remove emotion.
- **Diagnose before you act.** Decompose derived metrics into the five core inputs. Find the root cause.
- **Creative is the growth lever.** The algorithm handles targeting. Your job is feeding it diverse, high-quality creative.
- **Own the full funnel.** Ads, creative, landing pages, checkout, tracking — if it affects contribution margin, it is your concern.
