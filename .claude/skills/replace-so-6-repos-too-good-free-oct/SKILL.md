# 6 GitHub repos so good they should not be free (@replace.so)

Source: a carousel with a cover and five repo cards (a sixth was not in the upload). Stars are the card's own and unverified.

| Repo | Card says | Stars | Licence read |
|---|---|---|---|
| emcie-co/parlant | Open-source Python harness for customer-facing AI agents; control rules, tools, context, consistency, traceability | 18,297 | Apache-2.0 |
| basecamp/fizzy | "Kanban as it should be"; open-source issue and idea tracker; self-host with Docker, Kamal or ONCE | 8,251 | MIT |
| AutomaApp/automa | Browser extension to automate workflows by connecting blocks: fill forms, repeat tasks, screenshots, scrape, schedule | 21,662 | AGPL-3.0 |
| beekeeper-studio/beekeeper-studio | Cross-platform SQL editor and database manager (MySQL, Postgres, SQLite, SQL Server and more) | 23,758 | GPL-3.0 (community edition; a paid edition exists) |
| danny-avila/LibreChat | Self-hosted AI chat platform with multiple providers, agents, tools, file analysis, image generation, search | 45,924 | MIT |

## Cautions
- **[Certain]** Browser automation with Automa can submit forms and make purchases under your logged-in accounts; test on throw-away accounts.
- **[Certain]** Beekeeper's free edition omits some features of the paid edition; the cover's "shouldn't be free" is marketing.
- **[Likely]** Parlant is a framework for building agents, not a finished support bot; expect integration and evaluation work.
- Nothing was installed. Related: `martiendejong-10-oss-repos-vs-paid`, `replace-so-oss-repos-10`.
