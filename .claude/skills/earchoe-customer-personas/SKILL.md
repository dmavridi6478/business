# Inputs (slide 3)
Collect interviews, reviews, support questions or survey responses. Remove personal data you do not need before pasting anything into an AI tool. Core idea: AI is more useful when the raw material comes from real customers; Context -> Structure -> Check.

## Prompt 01 - cluster the language
```
Analyse these customer statements [TEXT]. Cluster recurring needs, frustrations, desired outcomes, objections and buying triggers. Quote only short phrases that are actually present.
```
## Prompt 02 - build the profiles
```
Create 3 evidence-based customer profiles from the clusters. For each, show the evidence behind the profile and clearly mark anything that remains uncertain.
```
## Rules
- Keep "observed" and "inferred" separate; that one distinction stops a persona becoming fiction dressed as research. You own the decision, the facts and the final output.
- Flow: evidence -> clusters -> profiles -> decisions. Use profiles for messaging, product decisions, onboarding and content themes.
- Save the evidence rule: keep the original input, the prompt that produced the useful result, add your own quality check before publishing or acting, then turn the finished workflow into a reusable template.
- This week: A analyse reviews, B cluster interviews, C build profiles, D improve messaging.
