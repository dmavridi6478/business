## Selection method (5 steps)

1. State the single job: find keywords, fix site health, optimise a page, win links, track rankings, or see whether AI assistants cite us.
2. Pick **one tool per category you actually need**; skip categories with no current owner. Five tools covering ten rings is normal.
3. Prefer a tool already connected (Ahrefs, Semrush) so Claude can query it; add a dedicated AI-visibility tracker only when AI citations are an explicit KPI.
4. For each candidate record price, seat limits and export options from the vendor's own page on the day of choice. The infographics give none.
5. Run a 30-day trial against one baseline metric (rankings for 20 keywords, or citation count for 20 prompts) before paying annually.

## Rules

- Do not claim a tool "ranks you higher"; tools measure and suggest, humans publish.
- AI-visibility trackers disagree with each other because prompts, models and sampling differ. Compare trends inside one tool, not absolute scores across tools.
- Pairs with: `ai-search-visibility`, `ai-seo`, `seo-audit`, `aeo-score`, `competitor-price-watchlist`.
