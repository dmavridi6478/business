# 50 Claude hacks (@aisimplified23), grouped

**Model 11-15:** Opus for the hardest work; Sonnet for everyday heavy lifting; Haiku for lightweight tasks; bigger context is not better context; match model to task.
**Claude Code 16-22:** treat it like an agent (goals, files, constraints); build a strong CLAUDE.md; plan before major changes; give verification steps; give the actual error; break huge builds into checkpoints; keep project instructions alive.
**Context and tokens 23-27:** compact long sessions; give relevant documents, not everything; put repeated instructions in Projects; set an output budget; cache repeated API context.
**Advanced 28-29:** give examples, not adjectives; separate thinking from execution.
**Cowork 30-35:** dedicated workspace; back up files first; automate repeatable work; package repeatable workflows; store context beside the work; give folder access intentionally.
**MCP and connectors 36-41:** connect tools only when needed; fewer good tools beat tool overload; start read-only; connect the development stack; connect work apps; MCP is the bridge.
**Skills 42-46:** turn repeated prompts into Skills; save best workflows; put instructions + resources together; build Skills around outcomes; improve Skills over time.
**Projects and memory 47-50:** use Projects as persistent workspaces; add your style guide once; separate permanent from temporary context; create a master source of truth.
