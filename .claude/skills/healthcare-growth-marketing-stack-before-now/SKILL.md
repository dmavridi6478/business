# Healthcare growth marketing stack, before and now (graphic)

Source: one graphic by Nathan Som (HealthBound Digital) mapping a "before" tool to the tools "now". It is an opinion, not a benchmark; no adoption or results data is given. Logos were not copied.

| Function | Before | Now |
|---|---|---|
| SEO and AEO | Semrush, Ahrefs, Moz | ChatGPT, Claude, Gemini, Perplexity, Grok (answer engines) |
| Outbound | Outreach, Salesloft | Instantly, Lemlist, Smartlead, La Growth Machine |
| CRM | Salesforce | HubSpot, Attio, Reevo |
| Paid ads | Google | Google (AI Max), YouTube, LinkedIn, X, Reddit |
| Design | Adobe, Figma, Canva | Figma, Canva, Gamma, HeyGen, Synthesia |
| Website | WordPress | Webflow, Figma, Framer, Lovable, Vercel |
| Workflow | Zapier | Clay, n8n |
| Data enrichment | ZoomInfo | AI Ark, Clay, Amplemarket, Apollo.io |

## Read it critically
- **[Certain]** "Before" tools are not dead: Semrush and Ahrefs remain the data sources that answer engines cannot replace (volumes, backlinks); answer engines show what is cited, not search demand.
- **[Certain]** In **healthcare**, outbound, enrichment and tracking tools handle personal data; HIPAA (US) or GDPR (EU) obligations apply, and ad pixels on patient pages are a known compliance risk. Get legal review; this skill is not compliance advice.
- **[Likely]** Cold outbound at volume risks domain reputation and spam-law breaches (CAN-SPAM, ePrivacy); warm up and honour opt-outs.
- Use as a checklist: for each row ask what the current tool costs, what it does that the newer tool does not, and what data you would have to migrate.
