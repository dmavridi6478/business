VLOOKUP vs HLOOKUP vs XLOOKUP

A lookup function searches for a value in a table or range and retrieves the corresponding information from that location.

V
Hi! I'm VLOOKUP
=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
lookup_value the value to search forcol_index_num the column number to return from[range_lookup] TRUE = approximate (default), FALSE = exact

What I am doing: searches vertically in the first column of a range and returns a value from the same row.

ProsEasy for vertical lookupsWorks in all Excel versions
ConsVertical onlyKey must be in the first column

H
Hi! I'm HLOOKUP
=HLOOKUP(lookup_value, table_array, row_index_num, [range_lookup])
row_index_num the row number to return from

What I am doing: searches horizontally in the first row of a range and returns a value from the same column.

ProsEasy for horizontal lookups
ConsHorizontal onlySlow on large datasets
X
Hi! I'm XLOOKUP
=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])
[if_not_found] value to return if there is no match[search_mode] search direction

What I am doing: searches one array and returns a value from a matching array or range.

ProsSearches in any directionDefault value if no match
ConsNewer Excel versions onlySyntax is a bit complex
