Approach A vs B

When to use which, in 60 seconds

A
Bounded
Evaluate predefined decisions
  • Input / context
  • Independent questions in parallel
  • Typed values + probabilities
Same context
ticket / state / query / document
B
Open-ended
Generate content, then validate
  • Input / context
  • Generate tokens
  • Text / JSON
  • Validate
  • Decision in code

Use A when

  • The answer space is known
  • Judgment is hard to hand-code
  • You need typed results
  • Probabilities inform thresholds
  • Code controls the action

Use B when

  • You need natural language
  • You need code generation
  • Summaries or explanations matter
  • The answer space is open-ended
  • The model must create content

Typed does not mean correct. Confidence does not grant permission.
