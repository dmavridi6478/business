# 12 things to do with Claude

The infographic lists capabilities and bullets but no prompts; the starter prompts below are mine. Each ends with the check that matters.

| # | Use | Starter prompt | Check before use |
|---|---|---|---|
| 1 | Build full websites | `Build a one-page site for [business] with sections [list]. Responsive, no external trackers.` (Artifacts or Claude Code) | Open on a phone; check links and legal text |
| 2 | Create AI agents | `Design an agent that does [task]: inputs, tools, steps, stop rule, and where a human approves.` | Run it on 5 real cases before trusting |
| 3 | Idea to working app | `Turn this idea into a minimal working prototype: [idea]. List what it does not do.` | Test edge cases and data storage |
| 4 | Automate daily work | `Map my routine [steps] to extract -> process -> report -> follow-up. Mark which steps need a human.` | Keep sending and publishing as drafts |
| 5 | Analyse datasets | `Clean this spreadsheet, list anomalies, then give 5 findings with the rows that prove each.` | Recompute one number by hand |
| 6 | AI-powered business | `Draft the repeatable systems for content, support, research and leads, with human approval points.` | See `ai-sales-human-split` |
| 7 | Presentations | `Turn these notes into a 10-slide outline for [audience], one message per slide.` | Verify every figure and source |
| 8 | Knowledge base (Projects) | Create a Project per area; upload files; set instructions once; reuse across chats | Remove client secrets before upload |
| 9 | Write and debug code | `Explain this code, find the bug, write a failing test first, then fix.` | Run the tests yourself |
| 10 | Research reports | `Market analysis of [topic]: findings, trends, competitors, risks, with source links.` | Open each source; models invent citations |
| 11 | Content machine | `Ideas -> research -> write -> repurpose for LinkedIn, X, YouTube.` See `content-week-7day` | Brand and proof check |
| 12 | Custom tools | `Build a calculator/dashboard for [need], inputs and outputs listed.` | Check the maths on known inputs |

The source repeats one theme worth keeping: **human approval where needed**. In this repo that means drafts only until the owner approves.
