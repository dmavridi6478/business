# 50+ must-have AI tools (Matic Pogladic cheat sheet)

Source: one dense graphic with a one-line description per tool. The descriptions on several tiles are duplicated or do not match the tool (for example the same sentence under Krisp, Writesonic, Anyword and Cleanvoice), so only the **names and groups** are recorded.

| Group | Tools as printed |
|---|---|
| Productivity and automation | Zapier, ClickUp, Calendly, Notion AI, Otter AI, Reclaim AI, Grammarly |
| Image and video generation | Leonardo AI, Synthesia, Midjourney, Stable Diffusion, Pictory AI, Veed GPT, DALL-E |
| Audio and voice | Fireflies AI, AIVA, Murf AI, Krisp, Descript, Cleanvoice, Podcastle |
| AI writing and content | Jasper AI, Hypotenuse, CopySmith, Writesonic, MarketMuse, Anyword, Headlime |
| Coding and development | Codey (Google), Data Analyst GPT, Replit Ghost Writer, GitHub Copilot, Tabnine, Code WP, Grimoire |
| SEO and marketing | Surfer SEO, Yoast SEO, Semrush, INK, SEO Robot, Ahrefs, SEO.AI, Tidio, HubSpot, Alli AI |
| Design and presentation | Slidesgo, SlidesAI, DesignsAI, Prezi, Vizcom, Visme, Gamma, Beautiful.ai, Canva, BoothAI |

## Read critically
- **[Certain]** The list is a snapshot of an earlier AI-tool era; names such as "Codey", "Veed GPT" and "Replit Ghost Writer" have been renamed or folded into other products, so check each is still sold under that name.
- **[Certain]** Count: the groups hold about 55 tools, so "50+" is accurate, but it is a directory, not a ranking; no evidence of quality is given.
- **[Likely]** Several tools overlap heavily (Jasper, Copysmith, Writesonic, Anyword); pick one per job.
- For vetted lists see `ai-tool-links-index`, `ai-tool-stack`, `ai-tool-finder`, `entrepreneur-tool-directory`. Prices and features were not checked.
