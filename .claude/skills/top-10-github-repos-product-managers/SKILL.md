## Vetting checklist (before any clone)
1. Open the repo page: does the owner/name exist, and is it the one on the slide?
2. Licence present? Last commit recent? Real contributors, not one bulk upload?
3. Read any skill, hook or script before installing; Claude Code toolkits can run shell commands (`/oss-repo-vet`, `/installer-safety-check`).
4. Prefer reading prompts and copying the useful lines over adding unreviewed hooks.
5. Do not paste confidential product data into third-party prompts.
