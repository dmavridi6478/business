# Personal brand strategy (Thomas Pearce)

| Branch | Element | Sub-elements (diagram) |
|---|---|---|
| Who you are | Niche | expertise, audience, platform |
| | Positioning | unique angle, category, authority |
| | Story | origin, turning point, mission |
| | Voice | tone, language, energy |
| | Content pillars | 3-5 themes, depth, range |
| | Proof | results, testimonials, case studies |
| | Offer ladder | free, low-ticket, high-ticket |
| How you grow | Content engine | formats, frequency, repurposing |
| | Distribution | organic, paid, collaborations |
| | Community | comments, DMs, inner circle |
| | Lead magnets | triggers, opt-ins, nurture |
| | Social proof | milestones, features, endorsements |
| | Monetisation | products, services, partnerships |
| | Optimisation | analytics, testing, iteration |

## My critique
It is a checklist, not a strategy: it does not say what to do first. Order I would use: niche and positioning, then proof, then one content pillar set, then distribution, then offer ladder, then lead magnets. Most people skip proof and jump to monetisation. Pick one platform for 90 days before adding a second.
