## Read critically
- **[Certain]** VoiceStudio clones voices: use only your own voice or written consent, and note AGPL-3.0 if you modify and host it (`githubnow-top10-18-oct-2026`).
- **[Certain]** CLI-Anything and Paperclip give agents control of other software; run them in a sandbox with limited accounts and spend limits.
- **[Likely]** The star totals are very high for young projects; the same author's other lists disagree on counts, so check on GitHub (`martiendejong-10-oss-repos-vs-paid`).
- **[Likely]** A security audit by an AI agent finds some issues and misses others; treat it as a first pass, not a clearance.
- Already here: `hyperframes`, `claude-design-skills-top5` (Impeccable). Nothing was installed.
