# Marketing Psychology

Source: "5 Skills [that make Claude write better content]" carousel (@ai_slacker), Skill 03. Helps Claude use proven behavioral principles to craft messaging, instead of applying persuasion tactics at random.

## Purpose

Understand *why* a message works, not only how it sounds. Random persuasion tricks stacked together read as manipulative and often contradict each other; picking the one principle that actually fits the situation reads as confident and true.

## The principles

| Principle | What it does | When it fits |
|---|---|---|
| **Framing** | Frame the message to shape perception | Choosing which fact leads — "90% success rate" vs. "10% failure rate" says the same thing, lands differently |
| **Social proof** | Show others are doing it too | When the audience is risk-averse or unsure — "join 10,000 teams already using this" |
| **Anchoring** | Use a reference point to influence judgment | Pricing pages (show the higher tier first), before/after comparisons |
| **Curiosity** | Spark interest by creating an information gap | Headlines, subject lines — a named gap the reader wants closed |
| **Loss aversion** | Highlight potential losses more than gains | When inaction has a real cost — people weigh avoiding a loss more heavily than an equivalent gain |
| **Specificity** | Concrete numbers/details over vague claims | Any claim that would otherwise read as generic marketing filler |
| **Pricing context** | Frame a price against a relevant comparison | "$29/month" vs. "less than a coffee a day" — anchors the number against something the reader already has a feel for |
| **Decision friction** | Reduce the number of decisions the reader has to make | CTAs, checkout flows, onboarding — every extra choice is a chance to abandon |

## How to use it: Principle → Message → Action

1. **Principle**: pick the one psychological principle that actually fits this message and audience — not the one that's easiest to write, and not multiple stacked together.
2. **Message**: craft the copy using that principle deliberately — the reader should feel the effect without being able to name the technique.
3. **Action**: the principle should point toward one guided action, not just create a feeling with nowhere for the reader to go.

## Choosing the right principle

| Situation | Reach for |
|---|---|
| Reader is unsure whether this is credible | Social proof |
| Reader is price-sensitive | Anchoring or Pricing context |
| Reader is comparing options and stalling | Loss aversion (cost of inaction) or Decision friction (make choosing easier) |
| Message reads as generic/forgettable | Specificity |
| Headline/subject line isn't earning the open/click | Curiosity or Framing |

Don't apply all eight to one piece of copy — like the prioritization frameworks in `business-decision-frameworks`, these solve different problems, and stacking them produces copy that reads as manipulative rather than persuasive.

## Output conventions when using this skill

- State which principle a piece of copy is using and why, before or alongside the draft — this makes the choice reviewable and correctable, not just asserted.
- Never fabricate the social proof, numbers, or comparisons these principles need to work — if there's no real customer count, no real result, or no real price comparison available, say so rather than inventing one to fit the principle.
- Reserve loss-aversion framing for situations where inaction genuinely has a cost — using it when there's no real downside to waiting reads as manufactured urgency and erodes trust.
