# Mobile app stack (slides)
- **Expo** (expo.dev): React Native without the native setup; site shows 50K GitHub stars, 3M+ developers.
- **Supabase** (supabase.com): backend and auth in one place: Postgres, auth, edge functions, realtime, storage, vectors. Connector present here (needs the project owner's authorisation).
- **RevenueCat** (revenuecat.com): subscriptions without receipt parsing; site claims 150K+ apps, $17B+ processed.
- **Figma** (figma.com): every screen before a line of code. Connector present here.
- **TestFlight** (developer.apple.com/testflight): beta testing and real feedback before the App Store.
- **Slothy**: the example app, "the most frictionless to-do list on the App Store".
Earlier founder-stack carousel from the same account: see `swap-5-dotdevs-subscriptions` and `ai-app-stack-2026`.

# Tiny dev tools
- **Carbon** (carbon.now.sh): code screenshots that look good. · **Excalidraw** (excalidraw.com): hand-drawn-style diagrams; browser storage can be cleared, save to file. · **regex101** (regex101.com): explains each part of a regex, flavors PCRE2/JS/Python/Go/Java/.NET; Pro features exist. · **HTTP Status Dogs** (httpstatusdogs.com): every status code explained by a dog. · **transform.tools** (transform.tools): convert between formats (SVG to JSX, JSON to TypeScript and more) without a script.
Privacy: do not paste secrets, tokens or customer data into web tools; Carbon, regex101 and transform.tools are hosted services.
