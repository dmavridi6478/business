# AI Persona Builder

Build a distinctive content persona that makes AI-assisted writing sound like you, not like generic AI.

## Step 1 — Define Your Persona

```
Help me define my content persona for AI and side hustle content.

About me: [your background, skills, what you have built]
My audience: [who I want to attract]
3 creators I admire and why: [list them]
The gap I see in my niche: [what most creators are not saying]
Words that describe my ideal tone: [give 5]

Give me:
1. My persona statement (2 sentences — who I write as)
2. My 3 non-negotiable style rules
3. 5 phrases I should use often
4. 5 phrases I should never use
5. The one POV that makes me different from everyone else in this space
```

## Step 2 — The Persona Formula (use this as your system prompt)

```
You are [specific expert identity].
Your audience: [who they are — specific, not broad]
Their biggest problem: [what keeps them up at night]
Your style: [3 words — e.g. direct, practical, zero fluff]
What you never do: [e.g. never use jargon / never be vague / never use motivational clichés]
Your signature approach: [what makes your POV different]

Write [content type] about [topic].
The output should make the reader feel: [curious / relieved / validated / challenged]
```

## Step 3 — Chain Prompting (run in sequence)

**Draft** — run the persona formula prompt above

**Sharpen:**
```
Make the opening line more provocative. Make it a bold claim under 8 words.
```

**Compress:**
```
Cut 20% of the words without losing any meaning. No filler.
```

**Voice check:**
```
Read this back and flag any line that sounds like generic AI content — not like the expert persona.
```

## Step 4 — Quality Test

Before posting: read it aloud.

- If it sounds like something you would say to a friend who asked for honest advice — publish it.
- If it sounds like a LinkedIn post from 2019 — run the chain prompts again.

## Where to store your persona

Paste the output of Step 1 into your Claude Project instructions so every conversation starts in character.
