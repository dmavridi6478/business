# SEO Backlink Strategy System

A complete backlink-building playbook organized around the System Wheel: **Prospect → Qualify → Package Value → Outreach → Verify → Iterate**.

---

## Competitor Backlink Intelligence

### Find Competitor Backlinks
```
Generate a list of top competitors in [industry/niche] including emerging + incumbents.

Identify likely backlink sources that link to [competitor URLs] — resource pages, roundups, associations, vendors.

Analyze competitor link-building patterns: content types, cadence, anchor tendencies, referring domain categories.

Cluster competitor backlinks by intent: citations, editorial mentions, guest posts, partnerships, tools, scholarships.

Suggest replicable strategies for [my site] with lowest effort → highest impact order.

Create personalized outreach templates to acquire similar links without copying content.
```

---

## Backlink Strategy Builder

### Gap Analysis
```
Analyze backlink gaps for [website URL] vs [competitors]; prioritize by relevance + attainable targets. Show which high-authority domains link to competitors but not to us, and why each gap is winnable.
```

### Directory & Citations Plan
```
Create a directory/citation acquisition plan for [industry] with submission fields checklist. Include niche directories, chamber of commerce, association listings, and local aggregators. Prioritize by domain authority and relevance.
```

### Guest Posting System
```
Build a guest posting pipeline: targets, angles, author bio variables, editorial guidelines checklist. For [industry], find publications that accept guest contributions, their topic focus, word count requirements, and link policies.
```

### Anchor Text Distribution
```
Propose anchor distribution for [website]: branded, partial match, topical, URL, generic; include risk notes. Current distribution analysis: what percentage of each type is safe vs what triggers over-optimization signals.
```

### Quality Metrics
```
Define backlink quality scoring rubric: topical match, organic traffic signals, editorial standards, link placement. Create a scoring system (1–10) I can apply to every link opportunity before pursuing it.
```

### Toxic Link Handling
```
Audit and categorize [website]'s backlink profile. Flag toxic links: paid links without disclosure, spammy directories, link farms, exact-match anchor over-optimization. Provide a disavow file and outreach-to-remove template.
```

## Digital PR Backlinks (Editorial-Grade)

```
Generate press release headlines for a link-worthy asset about [topic/data] with 10 angle variants.

Draft journalist outreach emails with personalization slots: beat, recent article reference, why-now hook.

Create expert opinion pitch angles: contrarian, forecast, myth-busting, data-backed.

Suggest PR campaign themes for [quarter]: seasonal + industry events + evergreen data stories.

Build media list segmentation: tier-1, tier-2, niche trades, local, podcasts; include pitch rules per tier.
```
*Note: Connectively responses must be concise, quotable, and credentialed.*

## Local Link Acquisition (Google Business Profile Aligned)

```
Generate local citation sites for [industry] in [city/region]; include niche + chamber + association listings.

Create sponsorship/partnership outreach scripts for local events, charities, schools, meetups.

Identify local bloggers, newspapers, community calendars, and radio/podcast sites for mentions.

Develop a Google Business Profile backlink strategy: landing page mapping, UTM guidance, posting cadence, local PR hooks.

Suggest hyperlocal content assets that attract links: neighborhood guides, statistics, local tools, annual reports.
```

## Influencer + Partner Link Collabs

```
Identify niche influencers and partner brands for [niche]; include collaboration fit scoring criteria.

Draft collaboration proposals: co-webinar, co-research, tool swap, resource inclusion, newsletter feature.

Generate co-branded content ideas designed to earn links: templates, calculators, benchmarks, swipe files.

Suggest guest podcast pitch scripts with credibility proof and episode topic hooks.

Create follow-up sequences (3-touch) for partnership nurturing with value-first positioning.
```

## Backlink Verification & Data QA

**Post-link placement checklist:**
- [ ] Confirm link exists on correct URL and page is live (HTTP 200)
- [ ] Verify target URL correctness + canonical alignment
- [ ] Check rel attribute (follow/nofollow/sponsored/ugc) and indexing signals
- [ ] Verify anchor text matches plan and is natural
- [ ] Check placement context (editorial body vs footer/sidebar)
- [ ] Capture evidence: screenshot + source URL + date acquired
- [ ] Track in sheet/CRM: domain, page URL, contact, method, cost, renewal terms
- [ ] Track in over time: domain, sarcote entire more
- [ ] Monitor over time: link removals, redirects, traffic impact, ranking movements

**Quality Scoring:**
- **High Quality, Low Risk**: Editorial, relevant, natural anchor
- **Low Quality, High Risk**: Spammy directory, unnatural anchor, paid

## System Wheel Reference

| Stage | Focus |
|---|---|
| **Prospect** | Find relevant sites, pages, journalists, partners |
| **Qualify** | Relevance, authority, traffic, editorial fit, link type |
| **Package Value** | Angle, asset, quote, data, co-marketing hook |
| **Outreach** | Personalized pitch, follow-ups, relationship building (manual) |
| **Verify** | Link placement, indexation, anchor, target URL, dofollow/nofollow |
| **Iterate** | Track results, refresh lists, improve angles, prune toxic links |

*ChatGPT / Claude accelerates research + drafting; humans execute outreach + relationships.*
