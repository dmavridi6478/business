## Read critically
- **[Certain]** The title says "GitHub repos", but DeepSeek-V3 is a model (weights), and the Claude Code tile links to claude.ai, not a repository.
- **[Certain]** Open WebUI's licence is custom (see `dotdevs-5-github-repos-for-ai-app`); Dify, n8n and others use their own terms. Read each licence.
- **[Likely]** A list of twelve with no ranking or evidence; pick by the job (workflow, local models, RAG, agents).
