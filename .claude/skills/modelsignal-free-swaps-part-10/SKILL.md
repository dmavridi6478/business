## Arithmetic
- The twelve annual prices add to **$5,508**, which matches the cover.
- The summary slide lists eight swaps (FusionAuth, dbt Cloud, Filestack, Chatbase, Lens, Tana, Fibery, CleanShot) that add to **$5,256**, yet is captioned "Save $5,508 a year". The $5,508 only holds if you take all twelve.
- "$0" excludes your hours, hosting, backups, security patching and any model or storage bills. Treat the saving as an upper bound.

## Use honestly
1. Pick swaps where a paid plan is more than about $300 a year and you already run servers.
2. Read each LICENSE before commercial use: AGPL-3.0 (EspoCRM, Logseq, Zitadel) and GPL (Jellyfin, Flameshot) have copyleft terms; Syncthing is MPL-2.0.
3. Run `/self-host-swap` and `/repo-licence-check` before relying on any of them.
4. "Comment FREE" is a lead-magnet prompt; nothing was commented.
