# Full-Funnel OS
1. **Planning** - "Are we running the right program for the right accounts?" Build on existing brand & demand; one sales & marketing team, one KPI; plan jointly with sales; cluster ICP on best deals (verticals -> shared use case); match account list to team capacity.
2. **Playbooks** - "How do we engage buyers with long buying cycles?" Match buying cycle & journey stage; combine program-based, signal-based and always-on plays; connect playbooks into account journeys.
3. **Enablement** - "How do we help teams implement as planned and scale initial success?" Document playbooks, timelines, responsibilities; coach; audit implementation; onboard new members; hold office hours.
4. **Visibility** - "Is the program being run as planned?" Quantitative (enough effort?), qualitative (right things, right way?), operational (following the right playbooks?).
5. **Reports** - "How effective is our GTM strategy?" Program dashboard: account velocity, leading indicators, lagging indicators.
Use with `abm-gtm-layers`, `gtm-strategy`, `icp`. `/gtm` can turn it into an audit table (score each part 0-3 with evidence).
