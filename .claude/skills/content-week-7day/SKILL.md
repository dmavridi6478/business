# One idea -> 7-day content plan

Principle from the source: do not ask AI for 30 random posts. Build **one idea into a sequence that teaches from several angles**. Input (real source and context) -> Think (structure, compare, test) -> Output (useful work product) -> Verify (human check before use). "AI is the accelerator; your source, judgement and verification create the value."

## Step 0 - the input (ask the user for all three)
1. Core idea - what should people understand?
2. Audience - who needs this?
3. Proof - examples or evidence you can actually show.
If any is vague, the output will be vague. Do not fill them in for the user.

## Prompt 01 - build the week
```
Core idea: [IDEA]. Audience: [AUDIENCE]. Proof/examples: [PROOF]. Build a 7-day content sequence where each day has a different job: problem → misconception → how-to → example → mistake → checklist → practical challenge. Give each day a hook and useful takeaway.
```

## Prompt 02 - add the progression
```
Now rewrite the sequence so no two posts teach the same point. Add one proof element to each post where possible: example, calculation, screenshot idea, mini case, demonstration or source.
```

## Second pass - cut the filler
1. Ask what it assumed (what did the model have to guess?).
2. Ask what is missing (what information would materially improve the result?).
3. Ask it to attack its own answer (weak claims, contradictions, edge cases).
4. Verify what matters - facts, figures, policies, prices, claims.

## Seven-day test checklist
One core idea - seven different jobs - one useful takeaway per post - proof wherever possible - filler removed.

## Business angle (slide 07/09), with my caution
The source suggests a content-planning service for founders and experts: one recorded conversation -> weekly content map -> scripts and carousels -> repurposing notes. Sell a defined result, a repeatable process and a clear quality check, not "I know how to prompt AI". Caution: recorded conversations contain client data; get consent before they go into any AI tool.
