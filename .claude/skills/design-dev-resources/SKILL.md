## When to use this skill

Reach for one of these instead of improvising when a task needs:

- **Illustrations** for a deck, landing page, or doc → unDraw
- **Brand/product logos as real SVG** rather than hand-drawn paths → SVGL
- **Pre-built landing-page component patterns** (hero sections, bento grids, glare/glowing effects) → Aceternity
- **A CSS glassmorphism effect** without manually tuning blur/opacity/refraction → Glassmorphism generator
- **Visualizing/debugging a JSON payload** as an interactive graph → JSON Crack

## Resources

| Site | What it's for | Link |
|---|---|---|
| unDraw | Constantly-updated library of free, open-source SVG illustrations, no attribution required | https://undraw.co |
| SVGL | Directory of ~665 real product/brand logos as copy-pasteable SVG | https://svgl.app |
| Aceternity | 200+ production-ready UI components/blocks/templates (Tailwind + Framer Motion) for landing pages | https://ui.aceternity.com |
| Glassmorphism generator | Generates the CSS (`backdrop-filter`, blur, refraction, border) for a glassmorphism effect and lets you copy it directly | https://glassmorphism.com |
| JSON Crack | Visualizes JSON as an interactive, explorable graph | https://jsoncrack.com |

## Notes

- Source: curated from a design-tools screenshot carousel ("Insane Website for Developers", @glorydotdev). Verify each site is still live and re-check licensing/attribution terms before using an asset in client-facing work — e.g. SVGL logos link back to the source product and note that permission may be required for some; unDraw is attribution-free.
- Treat these as free/open starting points, not a substitute for a client's actual brand assets when the logo or illustration needs to be pixel-accurate to their identity.
- Pairs well with the `frontend-design`, `web-artifacts-builder`, `campaign-page-one-shot`, and `premium-html-presentation` skills when those need real icons/illustrations instead of custom SVG paths.
