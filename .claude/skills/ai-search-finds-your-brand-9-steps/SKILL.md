# How AI search finds your brand (diagram)

Source: one diagram. It presents a **simplified model**, not a vendor-documented pipeline; the boxes ("LLM Search Console", "Extra Thinking Model") are the author's labels.

## The nine steps
1. **Ask a question** (user).
2. **Understand intent**: system prompt and query parsing.
3. **Refined question**: the query is refined.
4. **Find sources**: the model calls retrieval agents.
5. Retrieval agents: **A** public web sources (blogs, news, social posts), **B** search engines.
6. **Deliver data** back to the model, optionally via an extra-thinking (reasoning) model.
7. **Final answer** built.
8. **Use memory**: short-term and long-term.
9. **Show output**.

## The two tips printed on it
- Retrieval agent A: **make content crawlable and public.**
- Retrieval agent B: **optimize for both Google SEO and AI retrieval.**

## Read critically
- **[Certain]** Which sources an assistant cites is decided by each vendor and changes; no one can guarantee being cited.
- **[Likely]** The two tips are sound basics: allow crawlers in robots.txt, publish clear, factual pages, keep entity facts (name, products, claims) consistent everywhere.
- **[Guessing]** Step 8 memory rarely affects which sources are cited in anonymous chats; it matters more for logged-in personalised answers.
