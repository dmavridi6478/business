# AI hustle flywheel

Source: a dense one-page cheat sheet. The module headings and bullets below are condensed from it. It contains no results data; treat it as a checklist, not proof that any tactic earns money.

## The flywheel (A)

1. **Define problem space** - niche, pain, outcome.
2. **Research and inputs** - sources, constraints, examples.
3. **Prompt and produce** - drafts, variants, assets.
4. **Package** - script, post, product, offer.
5. **Distribute** - platform fit plus hooks.
6. **Measure and iterate** - feedback refines step 1.

Principle: optimise for repeatability - same engine, different outputs.

## The modules

| Module | Core moves |
|---|---|
| B. Niche down (problem-solution alignment) | One audience + one urgent job-to-be-done; define pain -> promise -> proof -> path; state a content thesis in one sentence; build a vocabulary list of customer phrases and objections |
| C. AI-assisted freelancing (service stack) | Research, writing, ideation and ops assistants; client-ready deliverables go brief -> draft -> revision -> final; always include scope, assumptions, sources, version |
| D. YouTube attention system | Hook promise -> credibility -> open loop -> structured beats -> CTA; keep intros short, show value early, repeat the promise |
| E. Sell digital products | Validate with search intent, forums, reviews, competitor gaps; position "for [who] who want [result] without [pain]"; offer ladder free -> low-ticket -> core -> premium; copy blocks: problem, agitation, solution, proof, guarantee, CTA |
| F. Online brand output | Two pillars + one signature format; template library of hooks, outlines, CTAs; weekly batch -> schedule -> engage -> analyse; repurpose long-form -> clips -> threads -> newsletter; measure saves, shares, replies - not likes |
| G. Craft intent-aligned content | Map content to intent (learn, compare, decide, act); use audience language; add proof; end with a next action |
| H. Virtual assistance at scale | Standard intake form with constraints; QA checklist (facts, tone, formatting, links); timebox 20/60/20 (research/draft/polish); versioning v1, v2, final plus change log |
| I. Mastering research | Precise question with scope; structured queries (operators, synonyms, exclusions); separate primary from secondary sources; cross-check and note uncertainty; output summary + reasoning chain + citations |
| J. Data demystified | Clean (missing, duplicates, types), explore (distributions, correlations, segments), explain (visuals + narrative + decision) |
| K. Surveys | Objective first (what decision will change?); neutral single-answer questions; reduce ordering and leading bias; check for speeders; translate results into do / stop / test next |
| L. Nail your interview | STAR (Situation, Task, Action, Result); role match skills to the job requirement; top 6 stories; avoid rambling and vague claims |
| M. Productivity | Time-box and priority stack; daily top 3 plus a weekly planning ritual; deep-work blocks; triggers -> routine -> reward loops; sustainable cadence with recovery blocks |
| N. Business applications | Marketing angles and landing-page variants; support macros and KB drafts; PRDs and iteration summaries; outreach personalisation and objection handling; SOPs and internal FAQs. "Ship faster, then refine with real feedback" |
| O. Additional resources | Official docs first; community discussion for edge cases; track feature releases; save links and summarise into your own playbook |

## Rules

- Every pass through the flywheel ends with one measured number; no number = the loop is not closed.
- Disclose AI assistance to clients where contracts or platforms require it; never present AI output as verified research without checking sources.
- Income claims need evidence from the user's own results; this skill never promises earnings.
