# Rewrite Boring Business Copy With AI

Source: @earchoe carousel "Use AI to rewrite boring business copy". Principle: AI is the accelerator; source material, judgement and verification create the value.

## Workflow: Input -> Think -> Output -> Verify

1. Input: real source copy plus context. Give the model the actual customer, offer, proof and next step (Source / Audience / Action).
2. Think: structure and compare before writing.
3. Output: a useful work product.
4. Verify: a human check before anything is used or published.

## Prompt 1 - Clarify the message
"Rewrite this copy for [AUDIENCE]: [PASTE COPY]. First identify: what is unclear, what is unsupported, what is repetitive, what the reader still needs to know. Then rewrite it in plain language while preserving every factual claim."
Before use: replace every [BRACKET]; attach source if needed; read and verify before use.

## Prompt 2 - Write the variants
"Create three versions: concise, conversational and more formal. Keep the meaning consistent. Then list any sentence that should be verified before publishing."

## Remove the AI-sounding parts (second pass)
The first AI answer is a draft. Ask it to: state what it assumed; state what information is missing; attack its own answer (weak claims, contradictions, edge cases); and flag what must be verified (facts, figures, policies, prices, claims).

## Copy-quality checks (save this list)
1. Keep the facts intact. 2. Remove jargon. 3. Make the next action clear. 4. Do not invent proof. 5. Read it as the customer.

## One message, several assets
One clear message can power websites, proposals, emails, product pages and internal documents. What you sell is a defined result, a repeatable process and a clear quality check. Not "I know how to prompt AI".
