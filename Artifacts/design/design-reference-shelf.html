Core Design Tools

Reach for one of these instead of improvising when a task needs illustrations, logos, components, effects, or asset inspection.

Site What it's for Link
unDraw Free, open-source SVG illustrations — no attribution required, constantly updated undraw.co
SVGL ~665 real product/brand logos as copy-pasteable SVG svgl.app
Aceternity 200+ production-ready UI blocks/templates (Tailwind + Framer Motion) for landing pages ui.aceternity.com
Glassmorphism generator Generates CSS for glassmorphism (backdrop-filter, blur, refraction, border) — copy directly glassmorphism.com
JSON Crack Visualizes JSON as an interactive, explorable graph for debugging payloads jsoncrack.com
Mobbin Real iOS & web app screens/flows from 1,000+ shipped products — study patterns before designing mobbin.com
Ecomm.Design Ecommerce sites filterable by platform/category — compare product-page UX patterns ecomm.design
UI.live Creator-shared UI snippets by component type (buttons, cards, dashboards, data viz) ui.live/components
Realtime Colors Preview color palette + font pairing on a real sample layout — 300K+ users, free realtimecolors.com
tweakcn Edit every shadcn design token against a live dashboard preview — 42 presets, no login tweakcn.com
Smooth Shadows Build a realistic layered shadow from one light source — copy as CSS or Figma layer smoothshadows.com
lucide-animated Lucide icons animated with Motion — add via shadcn CLI, MIT licensed lucide-animated.com

Design Inspiration Galleries

Reference sites for taste, not assets — browse before designing so a build doesn't default to the same template everyone else reaches for. Different galleries suit different jobs.

Site Best for Link
Awwwards Industry-standard award gallery, daily selections judged by a panel — high volume, current interaction trends, variable quality awwwards.com
Godly Smaller, higher bar — 3–5 new sites per week, no submissions or awards, pure curation. Open for high-end client work godly.website
SiteInspire Clean, restrained, European — 8,000+ sites filterable by style/type/subject. For whitespace and typography siteinspire.com
Land-book Built for SaaS landing pages specifically — filter straight to the pricing table or comparison grid you're stuck on land-book.com
Httpster Small studios, quiet design — typography-driven, independent, restraint over spectacle. For when loud isn't the answer httpster.net

AI Prompt Discovery Libraries

Browse other creators' actual AI image/video generation prompts — filterable by model, with one-click "use this prompt" flows. Adapt from real examples rather than writing from a blank page.

Site What it's for Link
Meigen.ai Gallery of AI-generated images/video, filterable by model (GPT Image, Seedance 2.0, Midjourney) — shows full prompt with "Use as Prompt" / "Use as Ref" buttons meigen.ai
Yesand.ai Prompt-attached image/video gallery browsable by category (Featured, Fashion, Collage, Video, Portrait) rather than by model yesand.ai
YouMind Prompts "World's largest free AI prompt library" — 20,000+ image/video/workflow prompts updated daily, in curated packs with "View full prompt" / "Try now" youmind.com/prompts
Attribution note: These are attribution-driven community galleries — prompts belong to individual creators who posted them, not the platforms. Browse and adapt directly rather than copying verbatim without crediting the source.

External AI Tools Worth Knowing

Not Claude Code skills — external SaaS products. Mention as options when evaluating tooling; don't assume access or an account exists.

Tool What it's for
Genspark Multi-agent AI workspace — one prompt fans out to research/writer/analyst/designer agents inside a shared project
Google Stitch Text/voice-to-UI — describes a screen or flow in plain language, generates a working interface draft
Google Flow AI video/scene-builder — storyboards and generates cinematic clips/scenes from text descriptions
Gumloop Visual AI workflow automation — chains triggers/AI steps/actions without code
Figma Make AI prototyping inside Figma — turns a design or idea into a clickable, interactive prototype fast
Kombai AI design engineer — turns a prompt into production frontend that reads as hand-made, not AI-default
Visily AI prototyping — turns a prompt, screenshot, or sketch into an editable UI concept
