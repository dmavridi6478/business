The Governed Marketing Team

Orchestrator + Specialists + Reviewer + Gates + Context

Who Talks To What

  • The human, orchestrator only
  • Specialists, packet only
  • Research, read-only everywhere
  • Context manager, the only writer
  • Reviewer, output not reasoning
1

Orchestrator

The Routing Layer
  • Restates the job in one sentence
  • Assembles the minimum context packet
  • Grants only the named tools
  • Splits two deliverables into two orders
  • Writes the definition of done
  • Routes every draft to the reviewer
  • Names why that specialist
  • Fails closed on missing context
  • Never writes deliverable content
6

Specialists

The Working Layer
  • Strategist
  • Content and repurposing
  • Research and analytics
  • Context manager
  • Social and distribution
  • Email and lifecycle
  • One remit each
  • One context packet each
  • One line on what they do not decide
1

Brand Reviewer

The Gate Layer
  • Brief, does it do the job asked
  • Claims, traceable to a proof row
  • Never reviews its own work
  • Channel, does it fit the format
  • Facts, checked against the source
  • Logs a revision event on every fail
  • Pass or fail with evidence
  • Specific failures, never general notes
  • No partial credit on claims
3

Gates

The Control Layer
  • No publish without a human
  • No claim without a proof row
  • No context, no start
  • Draft only, every specialist
  • Block until verified
  • Name the missing file and ask
5

The Context Files

The Foundation Layer
Brand filesVoice, proof, pillars, banned. Read by every specialist.
Reporting filesLast quarter — the numbers a strategy cannot be set without.
Health reportGaps per file, staleness past 90 days, which gaps block this week.
