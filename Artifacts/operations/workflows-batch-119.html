2. Claude add-on install triage

Run with prompt 4 in docs/batch-119-prompts.md. Source: the 40-things list and the claude-install-list-40 catalogue.

  1. List the jobs you doNot the tools you want
  2. Shortlist at most 5One per job
  3. Read README and licenceHooks, permissions, last commit
  4. SandboxThrowaway branch or profile
  5. MeasureTokens, time, errors
  6. Keep or removeRemove what you do not use
  7. Quarterly stocktakeRun skill-stocktake

Three of the 40 are memory systems, several are token savers, and a few repos have moved. Installing all of them adds context and risk without a gain you can measure.

3. Story drafting loop

Run with /tell-story then /story-check. Source: the 7 principles graphic.

  1. State the pointOne sentence plus the decision
  2. Gather true factsScene, mistake, cost, change
  3. DraftTension first
  4. Check 7 principlesScore 0 to 2 each
  5. Truth and permissionNo invented scene; names cleared
  6. Read aloudCut anything that is not the point
  7. Publish and note repliesDecisions made

Do not invent a scene or a quote to hit a principle, and keep the stakes honest.
