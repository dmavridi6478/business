1. AI side-hustle pilot loop

Source to sale in five steps with a go/no-go before any offer. Run with /side-hustle-pilot <idea>. Source: @earchoe carousel.

  1. Five-question filterReal person, demonstrable, verifiable, repeatable, paid outcome; any no stops
  2. SOURCEReal input and source material written down first
  3. AIPrompt 01 workflow, then Prompt 02 pilot
  4. CHECKAI result vs a human-made version; record where AI fails
  5. PACKAGEDeliverable, 3-step client process, QC checklist, offer text
  6. SELLYou approve and send; prices are structures, not promises

If the workflow cannot survive one real test it is not ready to sell. After a pilot: PROVE one measurable improvement, SYSTEMISE what repeats, EXPAND automation only where useful.

2. First-customer research

Find, track, close, learn with one customer group. Run with the customer-research skill (see references/first-customer-tool-stack.md). Source: @dotdevs series.

  1. FindF5Bot keyword + SparkToro audience report
  2. AskTally: what did you try before, and why did it fail?
  3. TalkYou contact people yourself; no auto-posting
  4. TrackTwenty: one contact, one opportunity, next follow-up
  5. CloseDocuSeal: sample PDF, signature fields, preview
  6. LearnFider: one request, votes and context

Mine public signal first (customer-research mode 2), ask second (mode 3). Record the lawful basis before any contact goes into a CRM. Connectors: Tally and n8n exist in the claude.ai directory (user authorises); none found for the other four.

3. Paid-to-free tool swap review

Decide whether a paid tool is worth replacing. Run with /oss-swap-17 or /oss-swap-12 (the 25-tool list lives in oss-alternatives). Source: @modelsignal Parts 17 and 12, @will.ai.m.

  1. PickOne paid tool you actually pay for
  2. VerifyRepo, stars, licence read from GitHub, dated
  3. Gap checkWhat the free tool does NOT replace
  4. Total costLicence + hosting + hours x hourly cost
  5. DecideSwitch, pilot or keep; you run any install
  6. Re-checkRe-run when the business changes shape

Three swaps carry three quarters of the Part 17 saving, so review the big lines first. Licences reading "Other" (Graylog, Arize Phoenix) need a human read before commercial use.
