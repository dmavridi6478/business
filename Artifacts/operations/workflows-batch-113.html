2. AI visibility check loop

Measure, fix, re-measure. Run with /llm-visibility-check <brand, category, location, rival>. Source: 25-prompt infographic; page types from the Searchable graphic.

  1. Fill bracketsOne set of values, kept constant
  2. Run x325 prompts, 3 runs, each assistant
  3. RecordNamed? position, sources, sentiment, false claims
  4. Fix false claimsCorrect the source page first
  5. Build page typeAuthority, decision or money page for the weak group
  6. PublishYou approve every page
  7. Re-run monthlySame prompts, compare

One run is a sample, not a measurement: answers vary by assistant, model, location and login. Metrics such as share of model are your own counts, not an industry standard.
