2. RevOps gated pipeline

A pipeline with four gates. Run with /revops-gate-check <CRM export>; read-only.

  1. Lead matchedMatched to an account; duplicate check done
  2. Rep routedOwner by rule; speed-to-lead timer running
  3. Stage checkedRequired fields complete; not stuck beyond N days
  4. Forecast rolled upValid close date and amount; variance computed

A record that fails a gate is held and listed; it is never silently fixed. Weekly output: pass and fail counts per gate, three oldest stuck deals.

3. Agent failure and recovery

Detect, understand, recover, resume, learn. Run with /agent-recovery <agent>; go/no-go review with /agent-prod-check. Source: "AI Agents Never Make It to Production" (Ismat Kamal).

  1. Detect failureErrors, exceptions, unexpected results
  2. UnderstandLogs, context, root cause
  3. Recovery optionsRetry · roll back · continue from a safe point · alternative tool
  4. EscalateWhen none of the options is safe
  5. Resume safelyContinue or hand over with full context
  6. LearnFix prompts, tools and process

Before launch, six questions must have confident answers: what can it access, what decisions can it make, what happens when it fails, how does it recover, who monitors it, can we measure its impact. Any "no" = not ready.

4. LinkedIn weekly acquisition routine

Forty-five minutes a day, one focus per day. Run with /linkedin-week. Source: "LinkedIn Client Acquisition in one page" (routine reconstructed from the page captions).

  1. Mon · WriteDraft the week's three posts
  2. Tue · Comment20 meaningful comments
  3. Wed · DMs20 messages from the shortlist; you send each
  4. Thu · Follow upReplies, booking in the DM
  5. Fri · ReviewReach, Accept, Reply, Call, Proposal, Won

The leakiest of the six numbers becomes next week's single fix. Stay inside LinkedIn's terms and GDPR; no scraping or bulk automation.
