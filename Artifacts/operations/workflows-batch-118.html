2. Finance model prompt run (Excel or PowerPoint)

Run with /excel-ppt-prompt. Source: the 10 Excel/PPT prompts.

  1. Copy the fileNever edit the only original
  2. Remove sensitive dataOnly approved assistants
  3. Run promptLive formulas, named ranges
  4. Tie-outTotals, debits equal credits, headline equals model
  5. Accountant reviewPrompts 3, 4, 6, 7 always
  6. Version and shareKeep the prompt and the file together

An assistant that edits your workbook can break formulas silently. The tie-out is the control.
