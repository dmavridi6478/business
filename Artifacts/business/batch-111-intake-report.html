1. Executive summary

Principal finding. Most of this batch is promotional content: carousels whose purpose is to collect follows, comments and stars. The material of real operating value is small: a security scanner to run before every future install, verified licence facts for 17 repositories, and a structured list of marketing automations that can be built on connectors already in this workspace. The rest is either already in the repository or cannot be obtained because it sits behind comment-to-receive gates.

  • Created: 8 skills, 7 slash commands, 2 agents, 4 design templates, 1 design theme, 2 documents and 1 user-run install script.
  • Verified: README and licence files of 22 repositories were read directly. Several slide claims were wrong or incomplete (section 5).
  • Scanned: the 8 new skills were scanned with SkillSpector in static mode. Five scored 0 to 7; three scored 29 to 30 (“caution”), all because the documents quote install commands. Findings were not suppressed.
  • Not done: nothing from the carousels was installed on any machine, no plugin was added and no connector was changed. Items that cannot be done from the cloud session are listed in section 8.

5. Source problems found

  • Automation list: 49 distinct items, not 50 (“Content Quality Reviewer” repeats). Three descriptions do not match their titles.
  • SEO graphic: eight areas, not twenty named agents. The lead-generation graphic shows folder names only. Both are comment-to-receive posts; their contents were not obtained and were not invented.
  • SkillUI: the slide gives no repository; the real project is amaancoderx/npxskillui (MIT). CryptPad: the real upstream is xwiki-labs/cryptpad (AGPL-3.0).
  • Add-ons: the Karpathy-derived repository has no licence file at its root, and is not made by Karpathy. ECC's README gives two different counts of its own contents.
  • NVIDIA figures (31,132 skills; 26.1% vulnerable; 5.2% malicious) could not be confirmed from the repository README. Star counts on all slides were not re-checked.

9. Prompts to copy and paste

Scan before install

Scan [path or URL] with SkillSpector in static mode only. Show the score, every finding with file and line, and tell me in plain words whether each one is a real risk or a text that only quotes a command. Do not install anything. Recommend install, install after fixes, or do not install.

Build one of the 50 automations

Build automation #[number] "[name]" from the ai-automations-50-marketing skill. Trigger: [trigger]. Inputs: [inputs]. Output: [output]. Use only these connectors: [list]. Stop at a human approval before anything is sent, posted or written to a CRM. Give me the step list, the exact prompt for the AI step, the fields it needs, a 10-example test plan, what could go wrong, and a run log format. Do not run it; show the plan first.

Personal brand map

Interview me with the 14 questions of the personal-brand-strategy-map skill, one at a time, starting with Niche. Do not answer for me. Score each element 0 to 4, name my weakest "Who you are" element, then give me a one-page brand sheet and a 30-day plan.

SEO team

Act as the seo-team-orchestrator for [site URL]. Goal: [traffic, leads or sales]. Market: [country, language]. Route the work through the eight areas in the claude-seo-team-8-areas skill in the run order. Use Ahrefs or Semrush only for numbers and date every figure. Give me the plan and the first two actions this week.

Lead generation system

Using the lead-gen-skill-map-10x10 skill, plan lead generation for [offer] aimed at [market, country]. Walk the ten folders in order, name the existing skill or agent and the connector for each step, mark what a human must do, and make every outbound message a draft for my approval.

Multi-agent campaign planner

Use the campaign-planner-multi-agent agent. Brief: [goal, audience, budget range, deadline, channels]. Run research, write, review and launch-plan as separate passes, stop before anything is published or spent, and list the decisions you need from me.
