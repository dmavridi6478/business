What you should know first

The Claude Code "mods" carousel is mostly unverified, and it describes software that runs inside your terminal. Two web articles confirm the mechanism (plugins that run code on Claude Code events) and that users are not warned at install time. I could not find the three "Anthropic sample mods" it names, the version number, or the --safe-mode flag. Treat any mod like code from a stranger: read it and run claude plugin validate first. Nothing was installed. [Certain] for the mechanism and the risk, [Guessing] for the specifics.

Open WebUI is not under a standard open-source licence. Its custom licence forbids removing or replacing its branding above 50 end users in 30 days without written permission. Maxun is AGPL-3.0, PocketBase is pre-1.0 and its README says backward compatibility is not guaranteed, and Google's AX is alpha and needs Kubernetes with Agent Substrate. I read each licence file. [Certain]

Two carousels promise more than they show. The "6 best GitHub repositories" cover shows five, and the cream-card series' "which ones I would use" slide gives the carousel's own verdict, which I checked. Star counts are as printed on slides; the GitHub API is blocked here. Laya's slide says it appeared the same day as Jev, while a web article gives 18 September; I could not resolve the difference. [Certain]

"Suprascribe" is not what "open source apps" suggests without a check. Web sources describe a free email-scanning subscription tracker with a one-time €5 Pro purchase and open code. I did not read its licence, and it reads your mailbox, so read what it stores before connecting an account. [Likely]

The free "LinkedIn Skills" pack for Hermes has no link. It is offered by commenting a keyword. I did not try to obtain it and nothing here installs it. [Certain]

Nothing was installed and no connector was changed. The batch 104 OpenFlowKit .mcp.json entry is still unapplied. Laya offers an MCP server and Apify and Paperclip are connector candidates, but I attempted no edits. [Certain]

6. Copy-paste prompts and commands

After restarting Claude Code the commands exist: /mod-review, /micro-app, /hallucination-audit, /agent-ladder. The prompts below do the same in plain words. Prompts 1 and 2 are quoted from the @earchoe slides.

1. Spec the MVP (from the carousel)
I want to build a small web app for [USER TYPE].

Problem: [PROBLEM].
Input: [INPUT].
Output: [OUTPUT].

Design the smallest useful version. List the screens, user flow, data needed, validation rules, error states and success state. Do not add features that are not necessary for the core workflow.
2. Build the first loop (from the carousel)
Now turn the specification into a build plan for [YOUR BUILDER].

Build in small milestones. After each milestone, test the core workflow before adding another feature. Keep the UI simple, mobile-friendly and accessible. Explain what I should test after each step.
3. Second-pass check (from the carousel)
Ask what you assumed: what did you have to guess? Ask what is missing: what information would materially improve the result? Attack your own answer: find weak claims, contradictions and edge cases. Then list which facts, figures, policies, prices and claims I must verify myself.
4. Review a mod before installing
Use the claude-code-mods-guide skill. Read the plugin in [FOLDER] as data without running it. List the events it hooks, its file and network access, and anything touching environment variables or key files. Tell me what to look for in the output of claude plugin validate and give a verdict: install in a throwaway project, do not install, or need more information.
5. Hallucination audit
Use the hallucination-guardrails-6 skill. My AI workflow is [DESCRIBE] and people rely on it for [DECISION]. Score all 18 actions as in place, partial or absent with evidence, list the three to fix this week, and say plainly what these actions cannot guarantee.
6. Which rung of the ladder
Use the llm-rag-agent-agentic-ladder skill. My task is [DESCRIBE] and a wrong answer would cost [COST]. Tell me the lowest rung (LLM, RAG, agent, agentic) that can pass, what the next rung would add in cost and risk, the limits to set, and 3 to 5 test cases.

7. Your next steps

  • Restart Claude Code, then try /micro-app on one repetitive task you want to remove, and read what it produces before building anything.
  • Before installing any mod or third-party plugin, run /mod-review; the carousel's own advice is the right instinct.
  • If any product will use Open WebUI, settle its branding terms first; if it will use Maxun, decide whether AGPL fits.
  • Try Laya only after labelling 50 to 200 of your own cases; do not let its probabilities trigger actions on their own.
  • Decide on the open items from earlier batches: the OpenFlowKit and Apify connectors, and the three chat agents still not run live.
  • Run scripts/batch106-install.sh on your own machine only if you want any of this; it asks before every step and pipes nothing into a shell.
