What you should know first

"These 3 will replace your entire startup stack" is a headline, not a finding. gstack is a set of prompts for Claude Code, ds4 runs one model family on Macs with 96 GB or more (or a DGX Spark), and gods-eye-view is a 3D globe of public data. None replaces a stack. All three are MIT-licensed; I read each licence. [Certain]

Several repos on these slides are not free to use the way the slides imply. HydraDB and Open-kritt are AGPL-3.0. Remotion's template depends on Remotion's own licence: free for individuals and companies of up to three employees, a paid company licence above that. RedInk is CC BY-NC-SA 4.0, non-commercial only. Echo-Music is GPL-3.0 and is an unofficial client that strips ads from YouTube Music, which is probably against YouTube's terms. [Certain for the licences; Likely for the terms]

PersonaLive can impersonate people. It animates one portrait photo in real time for live streaming. Its own README disclaims misuse. Use it only with the person's consent. [Certain]

Parts of the upload could not be identified. The "Editor" repo on the @replace.so slides names no owner, Img2threejs has several forks and I did not read a licence, AutoClip appears in the video only as a name, and the tenth @replace.so repo was not in the upload. I did not guess. [Certain]

5. Copy-paste prompts and commands

After restarting Claude Code the commands exist: /app-method, /repo-licence-check, /gtm-stage. The slides held no prompts, so all four below are mine.

1. Plan a small app (mine, from the 7-step carousel)
Use the app-building-method-7-steps skill. My app idea is [IDEA] for [USER]. For each of the seven steps give the one action to take this week, the named tool and a free alternative, and flag the data-protection, consent and testing gaps the carousel leaves out. Do not build anything.
2. Check licences before using a repo (mine)
Use the repo-licence-check command. Repos: [LIST]. My use is [internal only / hosted for customers / resold]. For each repo, read its licence, say whether my use is allowed, and name what needs a commercial licence or legal review (AGPL, Remotion company licence, CC BY-NC-SA, GPL). Say what you could not verify.
3. Place a company on a GTM stage (mine)
Use the gtm-infographics-9-cover skill. Our ARR is [X], customers [N], team [N], pricing [DESCRIBE], channels [LIST]. Say whether we are in Hustle, Focus or Expansion mode and why, then the pricing job, demo goal and channel count for that stage and one thing to stop doing. State that the stage bands come from a cover preview and are not a standard.
4. Triage today's trending repos (mine)
Use the github-briefing-oct4-three and github-5-repos-video-oct skills. I want to [GOAL]. Pick at most one repo from the two lists or say none fits. Give licence, install route from the README (never a piped download), what to read first, how to try it in a throwaway project, and what would make you reject it.

6. Your next steps

  • Before using any repo commercially, run /repo-licence-check with your use stated; the AGPL, Remotion and CC BY-NC-SA items are the ones that can bite.
  • If you want gstack, read its setup script and the existing gstack skill in this repo first; do not run team mode blindly.
  • For the app method, start with a spreadsheet and a free form before any paid tool, and add a privacy notice before analytics.
  • If you want the full GTM series, get the author's own graphics; the cover only previews five of nine.
  • Open items: the OpenFlowKit .mcp.json entry, and authorising the Midpage, Sentry and Supabase connectors.
  • Run scripts/batch108-install.sh on your own machine only if you want any of this; it asks before every step and pipes nothing into a shell.
