1. Executive findings

  • [Certain] The ten-agents card is a good rollout order and a risky default. It says "keep every agent on drafts", but several agents write to a CRM, research named people and read your inbox. I kept the ten instruction lines verbatim and added a rule per risk: a hard stop on sending, write limits (agent 5 adds a note; agent 9 only suggests), personal-data and outreach-law checks, prompt injection from inbound mail, and a one-agent-a-week rollout. Scheduled agents should rely on connectors: Anthropic says new scheduled tasks run in the cloud, but tasks that need local files run on your computer.
  • [Certain] The PMM levels graphic is one author's picture. The scope descriptions (one launch, one motion, the portfolio) are the useful part; the stack row and "#1 LLM tool" are examples and opinion. The skill adds a self-assessment and uses scope rather than title.
  • [Certain] The prompt sheet says 11 prompts but shows 6. I quoted the six and did not invent the other five. Prompt 2 asks a model to list topics a competitor "ranks for" from two URLs, which it cannot see; it needs a rank-tracker export or the answer is a guess.

  • I disagree with treating a tool stack as a career level. Buying Gong does not make anyone staff.
