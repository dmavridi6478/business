What you should know first

One of the two zips was a repeat. dbdbd955-iCloud_Photos.zip is byte-identical to the batch 108 archive (all 24 files match by checksum), so I did not process it again. The second zip held 15 new images. [Certain]

"Replace your subscriptions" tools are mostly copyleft, and you become the operator. Linkwarden, Plausible and Vaultwarden are AGPL-3.0; Paperless-ngx is GPL-3.0; only Uptime Kuma is MIT. Vaultwarden is an unofficial Bitwarden-compatible server, not a 1Password replacement as such: if you self-host a password vault, its security and backups are yours. [Certain]

Name collisions caught. A repo named 497974/foreman exists but is a different project from the Jev-supervising Foreman on the slide, which is thruwire/foreman (MIT, found through an article and confirmed from its README, which names TypeSafe's Jev). Aria-Icons' README says 340,000+ icons where the slide says 380,000+. [Certain]

Hardware and data caveats. Openjev needs an NVIDIA GPU or Apple silicon. Open-glean connects to Slack, Notion, GitHub and Gmail data. Repolyze sends repository code to a model. Aria-Icons' README offers a curl | bash install, which I did not use. [Certain]

The seventh repo on the @replace.so slides was not in the upload. Star counts shown (Foreman 505, Openjev 306, Open-glean 832) were not verified. [Certain]

Nothing was installed and no connector was changed. The batch 104 OpenFlowKit .mcp.json entry is unapplied. Midpage Legal Research, Sentry and Supabase still need your authorisation in a session that can run the sign-in. [Certain]

5. Copy-paste prompts and commands

After restarting Claude Code the commands exist: /self-host-swap and /jev-supervisor. The slides held no prompts, so the three below are mine.

1. Should I self-host this? (mine)
Use the swap-5-dotdevs-subscriptions skill. We pay for [PAID TOOL]; the team is [SIZE]; [PERSON] would maintain a replacement. Name the replacement and its licence, list what we take on (hosting, updates, backups, security, uptime) with an honest hours-per-month estimate, recommend self-host, hosted plan or stay, and give a one-week trial plan with a stop condition. Install nothing.
2. Plan a supervised coding-agent run (mine)
Use the replace-so-repos-7-jev-edition and laya-jev-ultrafast skills. The task is [TASK]; a wrong action would cost [COST]. Propose the worker, the supervisor's yes/no questions (stuck, tests passing, requirements met, needs verification, needs a human) and the action each score triggers. State what hardware or key each piece needs and what data leaves the machine. Give 5 demo-mode test cases and a rule for when a human must approve.
3. Licence check (mine)
Use the repo-licence-check command. Repos: [LIST]. My use is [internal only / hosted for customers / resold]. For each, read the licence, say whether my use is allowed and name what needs a commercial licence or legal review. Say what you could not verify.

6. Your next steps

  • Before cancelling any subscription, run /self-host-swap and trial the replacement for a week; the saving only exists if the upkeep is cheaper than the fee.
  • If you want to try Foreman, use its demo mode first and measure any Jev-style supervisor on 50 to 200 of your own cases, as in the earlier Laya notes.
  • Do not self-host a password vault without a backup and recovery plan you have tested.
  • Open items: the OpenFlowKit .mcp.json entry, and authorising the Midpage, Sentry and Supabase connectors.
  • Run scripts/batch109-install.sh on your own machine only if you want any of this; it asks before every step and pipes nothing into a shell.
