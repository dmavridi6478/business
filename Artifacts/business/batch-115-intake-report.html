3. What the slides omit

  • Oh My Zsh: the README's basic install is a piped curl | sh; the README itself recommends downloading and reading it first. It renames your existing .zshrc.
  • BCUninstaller: the README opens with "Looking for maintainers". Bulk removal can break software you still need.
  • WinDirStat: the README says it can open, move and delete files and recover deleted files, so it is more than a viewer.
  • ImageMagick: "200+ formats" is not in the README (it says "a wide range"). Restrict it when it processes untrusted files.
  • rich: the README says Python 3.8 or later while the slide badge shows 3.9 to 3.14.
  • AGPL-3.0 (Whitebophir, DeepDiagram, SearXNG): offer the source if you run a modified copy as a network service.
  • Springback: a self-promotion app in the @dotdevs carousel; not a tool and not assessed.

4. The two infographics

  • Positioning Triangle: three corners (target audience, unique value, differentiation) and the formula "I help [target audience] get [value] by [differentiator]". The four before-and-after examples and the four placements are from the slide; the checks (five-second self-identification, measurable outcome, one piece of proof, only numbers you can back) are my additions and are marked as such.
  • Nine GTM models: what each diagram shows is from the image; the "use it when" column and the sequence (who, proof, message and price, growth) are my reading. Van Westendorp sources define the marked points slightly differently; the skill states both conventions. The slide gives no sample sizes or sources and no evidence that one model beats another.
