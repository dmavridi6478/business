What you should know first

The "8 open source tools" carousel is the weakest source in this batch. Its product screenshots look like generated mockups (stock-style avatars, a "Sep 2, 2024" date in a post about 2026 tools), and its cover shows unrelated icons, including Notion, which is not open source. Jaaz is under a dual licence that bars team use and modification without a paid licence. OpenDraft drafts research papers, so it is not the writing workspace its slide shows. I could not find an InteraOne repo at all. The "$200/month" figure has no source. [Certain]

Two install commands on the design-skills slides are incomplete. UI UX Pro Max and Anthropic's frontend-design both need /plugin marketplace add ... before /plugin install ...; the slides skip it. Corrected commands are in the skill and section 7. [Certain]

I installed nothing and ran no installer. Installing third-party skills is not a neutral step: a skill is instructions your agent will obey, so each one deserves a read first. Octop and Hermes Agent install with piped curl | bash scripts, and Octop's is hosted on a cloud-storage bucket, not on github.com. [Certain]

The connector problem from batch 104 is still open. The OpenFlowKit entry for .mcp.json was refused last time, so I attempted no new connector edits. Notion and Higgsfield are already connected in this session, and Playwright is already in .mcp.json. Commands for the rest are in section 7 for you to run. [Certain]

JEV is real and its price checks out; the infographic leaves out the part that matters. $0.042 per million input tokens with free output matches two published write-ups. Both also report that confidence measures how concentrated the answer is, not whether it is right, and that injected text can move the answer. Never let a probability authorise an action alone. [Certain]

The attached CEO KPI infographic was already handled in batch 103 as the ceo-kpi-framework skill, including the corrected churn formula, so I did not duplicate it. [Certain]

One of my own flags was wrong and is removed. I first read OpenWhispr as dictation-only; its README also lists meeting transcription with speaker identification, so that slide is plausible. Star counts, follower figures and "6,000 stars in weeks" could not be verified; the GitHub API is blocked here. [Certain]

7. Copy-paste prompts and commands

After restarting Claude Code the four commands exist: /jev-or-llm, /design-skills-pick, /swap-stack-check and /governance-15. The prompts below do the same in plain words.

1. Jev or LLM
Use the jev-vs-llm skill. My task is [DESCRIBE THE DECISION]. Inputs are [WHAT GOES IN]. If it is wrong, [WHAT HAPPENS]. Tell me whether a typed decision model or an LLM fits, write the typed questions if it is Jev, and give me the labelled-sample test and thresholds I need before it gates anything. Do not call any model.
2. Pick a design skill
Use the claude-design-skills-top5 skill. My project is [MARKETING SITE / DASHBOARD / APP]. What looks wrong today: [DESCRIBE]. Recommend one primary skill and one backup, say which are already installed in this repo, and give the correct install steps and licence. Do not install anything.
3. Check a "try this instead" claim
Use the open-source-swap-stack-8 skill. Check this claim: [TOOL] instead of [PAID TOOL]. Find the real repo, read its licence, compare the README to the claim, tell me whether it is really open source for commercial use, and say what switching would cost. Clone into a scratch folder only and run no installers.
4. AI governance completeness check
Use the ai-governance-15-concepts skill. My AI system is [DESCRIBE] and it is at the [DESIGN / BUILD / DEPLOY / OPERATE / EVOLVE] stage. Score each of the 15 concepts as evidence seen, claimed only or missing, list the gaps by lifecycle stage, and name the three to fix first. State that this is not a compliance conclusion.
