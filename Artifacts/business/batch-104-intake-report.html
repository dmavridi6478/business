Batch 104 Intake Report

Two TikTok carousels of open-source tools, one carousel of local-first apps and one machine-learning video, turned into 3 skills, 3 commands, 3 design templates, a verified register of 15 repos, a runnable script and a user-run install script. Prepared for the owner of the business repository.

What you should know first

Most of your instruction list has nothing to act on. The two archives contain no prompts, no connector setup steps, no agent-building guide and no design brief. They are tool roundups: 16 tools and one advert, plus a short video of ML code. I did the parts that exist and say below which parts do not. [Certain]

"Free and open source" is not true of everything on the slides. AutoGPT's autogpt_platform folder is under the Polyform Shield licence (source-available, restricts competing use), and the slide shows a paid Pro plan. Three repos are AGPL-3.0 and Joplin is AGPL-3.0-or-later, so modifying and hosting them for others carries obligations. I read each licence file. [Certain]

The carousels are incomplete. One promises 6 repos and shows 5; the other promises 7 and shows 6, and its cover has a blue "n" icon with no slide. Star counts are copied from the slides and could not be verified (the GitHub API is blocked here); Busabase shows 313 on its slide and 224 in a search result. [Certain]

I installed nothing and ran no installer. The session runs in a disposable cloud container, so an install there would give you nothing, and Open Interpreter, Goose and nanobot offer curl | sh installers that I will not run on the strength of a screenshot. Repos were cloned shallowly into a scratch folder only to read licences and READMEs. [Certain]

The one connector I verified was not installed, because the edit was refused. OpenFlowKit publishes an MCP server (@vrun-design/openflowkit-mcp). I checked the npm package and prepared a pinned entry, but the permission system blocked the change to .mcp.json. I did not try another route. The one-line command is in section 6. [Certain]

The ML video is a set of fragments, not a program. The six lines use names the video never defines. I wrapped each in working context and ran it; k-means failed from a bad random start until I added restarts. The accuracy figures describe toy data. [Certain]

5. Connector: OpenFlowKit MCP

Package @vrun-design/openflowkit-mcp version 0.1.2: MIT, no install scripts, three dependencies (@modelcontextprotocol/sdk, pako, zod), published 6 June 2026, maintainer and repository match the GitHub project. It runs locally over stdio with no API key. A pinned entry was prepared for .mcp.json and blocked by the permission system, so it is not installed. Other connectors named in the files (Nanobot, Goose, Busabase) are general MCP claims with nothing specific to install. [Certain]
