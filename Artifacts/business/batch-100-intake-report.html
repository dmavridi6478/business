What you should know first

The useful result is a security baseline of your own repo. I installed gitleaks and osv-scanner and ran them here. gitleaks found 11 hits across 258 commits and all look like placeholders or upstream test fixtures. osv-scanner found 191 known advisories in 11 dependency manifests, all inside vendored skill folders.

Do not install dependencies inside those skill folders without reviewing them. The largest are cookie-sync (81 advisories), agent-platform-tuning (80) and the safe-browser template (45). They matter only if someone runs npm install or pip install there. I did not change them because they are upstream copies.

The Flowise site screenshot shows a banner "We're sunsetting Flowise". I could not confirm it from the README, so check before building on it. Flowise and Hexabot also show no LICENSE file at the repo root.
