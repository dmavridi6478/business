1. Result

The 36 slides held five design skills for AI-built screens, a homelab monitoring set, six Rust repositories, seven "start an agency" tools and five free design tools. Twenty-two repositories were checked and their licence files read. About half of the tools were already registered here, so the additions focus on the new ones: the five design skills, ntfy, Pingora, Microsoft Edit, Firecracker, Activepieces, Documenso, InvoiceShelf, Postiz, Squoosh and the Crest app.

Main findings, in order of importance. First, "open source" is mixed: Cap is AGPL-3.0 with MIT only for two crate families, Activepieces keeps an enterprise folder under a separate licence, and the Realtime Colors code is CC BY-NC-ND 4.0, so the free website cannot be forked into a product. Second, the slide install line for unslop only adds the marketplace and installs nothing. Third, Pingora is a framework for building proxies, not a drop-in Nginx replacement. Fourth, on the public ntfy server the topic name works as the password.
