Purpose

Explore, visualise and summarise data to understand its main characteristics, spot anomalies and guide later modelling.

Common measures

  • Central tendency: mean, median, mode
  • Dispersion: variance, standard deviation, IQR
  • Shape: skewness, kurtosis

Common visualisations

  • Histogram, box plot, bar chart
  • Scatter plot, correlation heatmap, pair plot

Checks to add

  • Missing values and duplicates
  • Outliers and impossible values
  • Leakage; correlation is not causation
Python (pandas, seaborn)
import pandas as pd, seaborn as sns, matplotlib.pyplot as plt
df = pd.read_csv("data.csv")
print(df.head()); df.info(); print(df.describe())
print(df.isna().sum(), df.duplicated().sum())
sns.histplot(df["age"], kde=True); plt.show()
