1. Assessment before you build

Read this first. It changes what you should build and in what order.

The infographic lists agent names. It contains no prompts.

CertainThe image gives 100 titles in 10 departments and a call to “comment CLAUDE for free access”. I did not see the original prompts, so every prompt in section 6 is written from scratch against a consistent standard. I did not reproduce a third-party pack.

One hundred prompts will not run a LinkedIn operation. Shared context will.

CertainAn agent with no knowledge of your audience, offer, proof and voice returns generic copy. That is the main reason pasted-prompt packs disappoint. The workflow below builds one Context Pack first and makes every agent depend on it.

Roughly a dozen of the hundred agents carry most of the value, and several overlap.

LikelyHook Generator and Hook Writer, Banner Creator and Banner Designer, Comment Responder and Comment Writer, and Analytics Overview and Report Generator are close duplicates. Start with the 12 agents marked “Core” in the library and switch others on only when a real task needs them. The System Auditor agent retires what you do not use.

Claude does not connect to your LinkedIn account in this setup.

CertainAnalytics agents work on exports or numbers you paste. Image, GIF and video agents produce briefs and prompts for other tools. Research agents need web access or sources you supply. Each prompt states this, and each card carries a tag when it applies.

Several agents in the original concept sit against LinkedIn’s rules.

CertainLinkedIn’s User Agreement prohibits scraping and unauthorised bots or automated activity. Data Extractor, Email Finder, Engagement Booster, Like Strategist and Network Expander are exactly where accounts get restricted. Here they are draft-only and manual-execution agents with daily caps, and they never claim to send or collect anything.

Lead generation is where your legal exposure sits.

LikelyYour Greek-language requirements suggest EU operation. If so, GDPR applies to prospect data: lawful basis, source, retention, opt-out. The Email Finder, Contact Verifier and Data Extractor prompts build that check in. They do not replace advice from a data-protection professional.

6. Agent library: 100 prompts

Every prompt uses the same template: role, context, mission, inputs, process, output format, rules. Tags show what each agent needs or risks. Use the filters, then copy a prompt or a whole department.

7. Governance

These rules are written into every prompt and apply to you as well.

  • Draft only. No agent posts, sends, connects or scrapes. You perform every action in LinkedIn yourself.
  • Daily caps. Set connection requests, messages and comments per day in the Context Pack and keep them modest.
  • No pods, no bots, no automated reactions.
  • Fact gate. Every number, quote and client example is checked by you against a source before publishing.
  • Personal data. Record source, purpose and lawful basis for every prospect. Honour opt-outs. Delete on request.
  • Client confidentiality. Case studies are anonymised unless you hold written permission.

Set targets from your own baseline in week 1. The measures that matter are qualified conversations per week, meetings booked, the share of engagers who match your ICP, and profile visits from the ICP. Impressions and follower count are secondary.

The risk in this plan: a well-run agent system makes it easy to publish more than you have to say. Volume without a clear position erodes credibility faster than silence. Let the Content Strategy pillars, not the number of agents, set your posting rate.
