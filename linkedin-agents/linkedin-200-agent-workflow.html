The strongest idea in the design is the diagnostician, and it only works if you run it.

LikelyEvery division ends with a diagnostician agent. That is a weekly feedback loop: find the biggest drop in the division, name a cause as a hypothesis, test one change. Most agent packs have no equivalent. Run all four of your diagnosticians every week and ignore the rest if you must.

The “keeper” and “tracker” agents cannot keep anything unless you give them a place to store it.

CertainClaude does not remember between separate chats. A calendar-keeper, off-limits-keeper or crm-hygienist works only if the register lives in project knowledge, a spreadsheet, your CRM or your ATS, and you paste it back in each run. Every prompt here returns the full updated table so you can save it. Name the system of record in the Context Pack.

The infographic caps sends at 20 a day, account-wide. Treat that as a ceiling you earn, not a safe number.

CertainThe cap is printed on the image, and I use it as the default send budget in the Context Pack. GuessingWhether 20 a day is safe for your account, I cannot know, since LinkedIn does not publish its limits. Start lower, watch for warnings, and raise it slowly. The agents draft; you send.

Several agents are built around actions LinkedIn prohibits when automated.

CertainLinkedIn’s User Agreement prohibits scraping, bots and sharing account access. post-engager-harvester, competitor-engager-harvester, client-list-builder, unified-inbox-router and account-provisioner sit exactly there. Here they work from names and posts you review and paste manually, and for client accounts they use native admin roles and client-approved drafts, never shared passwords.

Recruitment and Agencies carry legal exposure that Coaches and Sales do not.

LikelyIn the EU, AI used to filter or evaluate job candidates is treated as high-risk under the AI Act. Check the current application dates, which have been under revision. Candidate data also falls under GDPR and anti-discrimination law, and pay-transparency rules differ by country. The candidate-screener prompt recommends against job-related criteria only and never rejects automatically. Agencies handle several clients’ confidential data, so each client gets a separate Project and the cross-client-deduper works from IDs only. None of this replaces advice from a qualified professional.

6. Agent library: 200 prompts

Every prompt uses one template: role, context, mission, inputs, process, output format, rules. Choose a vertical, then copy a prompt, a division pack or the whole vertical. Typing in the search box searches all 200.

7. Governance

  • Draft only. No agent posts, sends, connects, scrapes or logs in anywhere. You perform every action.
  • Send budget. One account-wide daily cap in the Context Pack, default 20 as printed on the infographic. Every outbound agent counts against it and refuses to draft beyond it.
  • Agencies. The client approves every post and message before it goes out. One Project per client. No shared passwords; use native admin roles.
  • Recruitment. Agents recommend and you decide. Job-related criteria only. Record purpose and retention for candidate data.
  • Fact gate. You check every number, quote and case study against a source before publishing.
  • Personal data. Record source, purpose and lawful basis for every prospect or candidate. Honour opt-outs. Delete on request.

Set targets from your own week-1 baseline. The measures that matter are qualified conversations per week, meetings or briefs booked, and the share of engagers who match your ICP. Impressions and follower count are secondary.

The risk in this plan: 200 agents make it easy to mistake activity for progress. Add an agent only when a diagnostician shows that stage is your biggest drop.
